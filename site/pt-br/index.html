O jeito XTree, num terminal moderno

O Xylem é um gerenciador de arquivos em modo texto para Linux, inspirado no XTree e no ZTreeWin: árvore de diretórios, tags e operações em grupo, as teclas do ZTreeWin — e ainda terminal embutido, máquinas remotas via SSH, Git e temas.

Instalar Código no GitHub

Livre e de código aberto (MIT) · Linux x86_64 e ARM64 · Windows (experimental)

xy ~/projetos

O que ele faz

Tudo o que você lembra, e mais

O Xylem segue as teclas e o jeito de trabalhar do ZTreeWin sempre que possível, então seus dedos já o conhecem. E acrescenta o que um gerenciador de arquivos precisa hoje.

O jeito XTree

Uma árvore de diretórios logada na memória com a janela de arquivos embaixo, Branch e Showall para listar os arquivos de um ramo inteiro ou de tudo o que foi logado, e tags sobre as quais agem as operações em grupo.

Operações com arquivos

Copiar e mover com ou sem os caminhos, com progresso e detalhes dos conflitos. Apagar para a lixeira com Oops para restaurar, Prune, renomear com máscaras, permissões e datas, Compare entre duas janelas.

Achar coisas

Filespec por nome, data e tamanho, Treespec para digitar um caminho, bookmarks, e Ctrl+S para buscar texto nos arquivos marcados.

Olhar dentro e editar

Um visualizador de texto e hex com busca, quebra de linha, numeração e cores de sintaxe, um modo tabela com filtro SQL para planilhas, CSV, JSON Lines, DBF, SQLite e Parquet, arquivos Markdown renderizados, além do Autoview ao lado da lista. E abre seu editor de texto ou um editor hexadecimal (hexedit, heh, bvi, dhex) direto dentro da moldura e com o tema do Xylem — ou desativa a edição binária no F12.

Batch sobre registros

Ctrl+B transforma arquivos marcados, os registros de uma tabela ou as linhas de um texto em script, JSON, CSV, XML, HTML, SQL ou um banco SQLite, com escapes que mantêm dados hostis no lugar.

Duplicados

Alt+Y acha arquivos e pastas inteiras com o mesmo conteúdo, sem baixar nada de um Google Drive montado pelo rclone, e sempre deixa uma cópia.

Arquivos compactados

ZIP, 7z e TAR abrem como diretórios: navegue, veja e copie de dentro deles. Também dá para criar ZIP e TAR.

Terminal embutido

Alt+X abre um shell cujo cd leva a árvore junto; Alt+O digita os arquivos marcados no prompt.

Remoto e nuvem

Navegue e copie de máquinas via SSH, com o terminal de lá. Google Drive, Amazon S3 e uns 70 outros serviços via rclone.

Git e mais

Um menu Git opcional com letras de status na lista de arquivos, a área de transferência, uma tela de configuração (F12) e doze temas.

Uso do disco

Para onde foi o espaço?

Alt+W lista as pastas e os arquivos de um ramo pelo espaço que ocupam, do maior para o menor, com a parte de cada um e, no painel ao lado, a data. Desça pasta por pasta até o que enche o disco: um backup antigo, uma ISO esquecida, um cache que cresceu. Um disco por vez, hard links contados uma vez e o espaço em disco como o du conta.

Na árvore, Alt+K → Percent mostra as mesmas partes ao lado de cada pasta. Apontado para um Google Drive ou um bucket S3 montado com o rclone, mostra também o que os enche.

Por que o Xylem?

Algo tão bom quanto o ZTreeWin, no Linux

Uso alguma variação do XTree desde a década de 1990 e tenho uma licença paga do ZTreeWin desde 2013. O ZTreeWin continua sendo, para mim, o melhor gerenciador de arquivos em modo texto, e Kim Henkel mantém vivo o jeito XTree no Windows há décadas. Desenvolvi o Xylem por sentir falta de algo tão bom quanto ele rodando no Linux: as versões que existem parecem abandonadas ou se afastaram demais do visual e do jeito clássicos.

O Xylem não pretende substituir o ZTreeWin. Ele também compila para Windows, porque o Rust torna isso fácil, mas isso não é prioridade: no Windows, o ZTreeWin vale muito a licença.

O que o Xylem tem, o que ainda não tem e o que deixa para outros programas está na comparação com o ZTreeWin.

O Xylem é um projeto antigo, que por anos eu mantive num repositório privado por falta de tempo. A primeira versão foi feita em Java, com o framework Lanterna, e ficou bem limitada: nunca sobrava tempo para ela. A chegada dos assistentes de código com IA mudou radicalmente a situação, e resolvi reativar o projeto e refazê-lo do zero, numa linguagem mais adequada para aplicações desktop. Java ainda é minha linguagem favorita, mas o Rust tem subido cada vez mais no meu conceito, à medida que eu o aprendo.

Mais sobre o XTree (em inglês): The XTree Fan Page, a história, as versões e as histórias do XTree, mantida pelos fãs há mais de vinte anos; o artigo da Wikipédia; e o ZTreeWin, que continua o jeito XTree no Windows, e o fórum dos usuários dele.

O nome: o xilema (xylem, em inglês) é o tecido que leva a água pela árvore — e começa com X, como o XTree.

Instalar

Funcionando em um minuto

O comando é xy. Rode xy para abrir o diretório atual, ou xy algum/diretorio.

Binário pronto

Baixe o arquivo para o seu sistema na página de Releases: Linux x86_64 ou ARM64 (estático, roda em qualquer distribuição) ou Windows x86_64. Depois coloque o xy no seu PATH:

tar xzf xy-*-x86_64-unknown-linux-musl.tar.gz
install -m 755 xy-*-x86_64-unknown-linux-musl/xy ~/.local/bin/

Cada arquivo tem um .sha256 ao lado, para conferir com sha256sum -c.

Pacote (.deb ou .rpm)

As versões a partir da 0.5.0 também têm pacotes para Debian, Ubuntu, Fedora, RHEL, openSUSE e derivados, x86_64 ou ARM64. Eles também instalam a entrada no menu, os ícones e a página de manual:

sudo apt install ./xylem-fm_*_amd64.deb
sudo dnf install ./xylem-fm-*.x86_64.rpm

Eles vêm da página de Releases, não de um repositório: para atualizar, instale o próximo do mesmo jeito.

Com o Cargo

Precisa do Rust, via rustup, e de um compilador C. No crates.io o Xylem se chama xylem-fm:

cargo install xylem-fm

Ou o código mais recente, direto do GitHub:

cargo install --git https://github.com/andrelnfernandes/xylem

Há também uma entrada no menu e uma página de manual (xy --man), e uma função de shell para terminar no diretório em que você estava ao sair com Alt+Q.
