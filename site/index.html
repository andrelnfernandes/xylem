The XTree way, in a modern terminal

Xylem is a text-mode file manager for Linux, inspired by XTree and ZTreeWin: a directory tree, tags and group operations, ZTreeWin's keys — plus a built-in terminal, remote machines over SSH, Git and themes.

What it does

Everything you remember, and more

Xylem follows ZTreeWin's keys and way of working whenever possible, so your fingers already know it. Then it adds what a file manager needs today.

The XTree way

A directory tree logged into memory with the file window below it, Branch and Showall to list the files of a whole branch or of everything logged, and tags that group operations act on.

File operations

Copy and move with or without the paths, with progress and conflict details. Delete to the trash with Oops to restore, Prune, rename with masks, permissions and dates, Compare between two windows.

Finding things

Filespec by name, date and size, Treespec to type a path, bookmarks, and Ctrl+S to search the tagged files for text.

Looking inside and editing

A text and hex viewer with search, soft wrap, line numbers and syntax colors, a table mode with a SQL filter for spreadsheets, CSV, JSON Lines, DBF, SQLite and Parquet, Markdown files shown rendered, plus Autoview next to the list. E opens your text editor or a hex editor (hexedit, heh, bvi, dhex) right inside Xylem's frame and color theme — or disables binary editing in F12.

Batch over records

Ctrl+B turns tagged files, the records of a table or the lines of a text into a script, JSON, CSV, XML, HTML, SQL or a SQLite database, with escapes that keep hostile data in its place.

Duplicates

Alt+Y finds files and whole folders with the same contents, without downloading anything from a Google Drive mounted by rclone, and always leaves one copy.

Archives

ZIP, 7z and TAR archives open as directories: browse them, view and copy out of them. ZIP and TAR can be created too.

Built-in terminal

Alt+X opens a shell whose cd takes the tree along; Alt+O types the tagged files at the prompt.

Remote and cloud

Browse and copy from machines over SSH, with their own terminal. Google Drive, Amazon S3 and some 70 other services through rclone.

Git and more

An optional Git menu with status letters in the file list, the clipboard, a configuration screen (F12) and twelve themes.

Themes

Not a fan of the classic blue?

Pick a theme with F4, or set theme in the configuration file. Every color can also be changed one by one.

Disk usage

Where did the space go?

Alt+W lists the folders and files of a branch by the space they take, largest first, with each one's share and, in the panel beside it, its date. Go down folder by folder to what fills the disk: an old backup, a forgotten ISO, a cache that grew. One disk at a time, hard links counted once, and the space on the disk as du counts it.

In the tree, Alt+K → Percent shows the same shares next to each folder. Pointed at a Google Drive or an S3 bucket mounted with rclone, it shows what fills them, too.

Why Xylem?

Something as good as ZTreeWin, on Linux

I have used some flavor of XTree since the 1990s, and I have had a paid ZTreeWin license since 2013. ZTreeWin is still, to me, the best text-mode file manager there is, and Kim Henkel has kept the XTree way alive on Windows for decades. I wrote Xylem because I missed something as good as it running on Linux: the existing alternatives seem abandoned or have drifted too far from the classic look and feel.

Xylem is not meant to replace ZTreeWin. It also builds for Windows, because Rust makes that easy, but that is not a priority: on Windows, ZTreeWin is well worth its license.

What Xylem has, what it does not have yet and what it leaves to other programs are in the comparison with ZTreeWin.

Xylem is an old project of mine, which for years I kept in a private repository for lack of time. The first version was written in Java, with the Lanterna framework, and it stayed quite limited: there was never enough time for it. AI coding assistants changed that radically, so I brought the project back and rewrote it from scratch, in a language better suited to desktop applications. Java is still my favorite language, but Rust keeps rising in my esteem as I learn it.

More about XTree: The XTree Fan Page, the history, versions and stories of XTree, kept by its fans for over twenty years; the Wikipedia article; and ZTreeWin, which carries the XTree way on in Windows, and its users' forum.

The name: the xylem is the tissue that carries water through a tree — and it starts with an X, like XTree.

Install

Get it running in a minute

The command is xy. Run xy to open the current directory, or xy some/directory.

Ready-made binary

Download the archive for your system from the Releases page: Linux x86_64 or ARM64 (static, runs on any distribution) or Windows x86_64. Then put xy on your PATH:

tar xzf xy-*-x86_64-unknown-linux-musl.tar.gz
install -m 755 xy-*-x86_64-unknown-linux-musl/xy ~/.local/bin/

Each archive has a .sha256 next to it, to check with sha256sum -c.

Package (.deb or .rpm)

The releases from 0.5.0 on also have packages for Debian, Ubuntu, Fedora, RHEL, openSUSE and their derivatives, x86_64 or ARM64. They also install the menu entry, the icons and the man page:

sudo apt install ./xylem-fm_*_amd64.deb
sudo dnf install ./xylem-fm-*.x86_64.rpm

They come from the Releases page, not from a repository: to update, install the next one the same way.

With Cargo

Needs Rust, via rustup, and a C compiler. On crates.io Xylem is called xylem-fm:

cargo install xylem-fm

Or the latest code, straight from GitHub:

cargo install --git https://github.com/andrelnfernandes/xylem

There are also a menu entry and a man page (xy --man), and a shell function to end up in the directory you were in when you quit with Alt+Q.
