# 鼠标

Xylem 是为键盘设计的，鼠标默认关闭，直到您将其打开：**F12**，第 2 页，**R**（或在[配置文件](configuration.md)的 `[options]` 中设置 `mouse = true`），然后按 **F3** 保存。设置立即生效。

鼠标从不拥有自己的命令。单击会选中一行，或者等同于您所点击位置上写着的按键，而该按键照常执行它一贯的操作：Delete 仍会询问，在此处无法运行的命令仍会被拒绝。

## 鼠标的作用

| 位置 | 单击 | 双击 | 滚轮 |
|---|---|---|---|
| 目录树 | 选中目录；文件窗口随之切换 | Enter：进入其文件 | 光标移动 3 个目录 |
| 文件夹前的标记 | `+` 展开它，`?` 载入并展开它，已展开文件夹的 `─` 将其折叠 | | |
| 文件窗口 | 选中文件并切换到文件窗口 | View，使用 Xylem 自带的查看器 | 光标移动 3 个文件（在多列模式下为一行） |
| 右边框上的滚动条 | 在滑块上方或下方：翻一页；拖动滑块可到达任意位置 | | |
| [分屏](split.md)的另一侧 | 使其成为活动窗口，然后选中 | | 移动该侧的光标，活动侧保持不变 |
| [内置终端](terminal.md)、框架内的编辑器 | 交给程序（如果它请求了鼠标：mc、vim、htop、tmux）；否则无操作 | | 交给程序（如果它请求了鼠标）；否则向上翻阅滚出屏幕的行，同 Shift+PgUp |
| 内置终端上方的目录树 | 返回 Xylem，同 Alt+X | | |
| 底部状态栏 | 该项的按键：`Copy` 即 C，`Esc cancel` 即 Esc，`Yes` 回答问题 | | |
| F12 | 更改一个选项，同按其字母（按 F3 之前不会保存）；预览列表中的主题（F4） | 选定该主题 | 移动选择 |
| 书签、搜索框、Usage、Duplicates | 选中该行 | 其 Enter | 3 行 |
| 输入框的历史记录（↑） | 把该条目放入输入框 | | 3 行 |
| 输入框的文本 | 光标移到该处 | | |
| 查看器中的表格 | 选中单元格 | 其 Enter：该记录 | 3 行；Shift+滚轮，一列 |
| 查看器、帮助 | 跟随帮助中的链接 | | 滚动，同 ↑ 和 ↓；Shift+滚轮使查看器横向滚动 |
| 任何适合出现菜单的地方 | 右键打开菜单（见下文） | | |

双击从不使用系统程序打开文件：不是您创建的文件可能是恶意的，误点一下不应运行它。Open（`O`）依然可用。

按住左键拖动会沿列表移动光标；拖过列表的上边缘或下边缘时，每移动一次列表滚动一行。

## 右键菜单

右键会像单击一样把光标移到指针下的项目上，并在指针旁打开一个菜单，列出可对该项目执行的操作。键盘上的 **Menu** 键或 **Shift+F10** 会为光标下的项目打开同一个菜单，无需鼠标。

| 指针下方 | 菜单 |
|---|---|
| 一个文件 | View、Edit、Open with the system、Info；Tag 或 Untag；Copy、Move、Rename、Delete、Attributes、New date、Yank the path |
| 一个文件，且有已标记的文件 | 同上，另有一组针对已标记文件：Copy、Move、Rename (mask)、Delete、View、Yank、Untag all |
| 目录树中的一个目录 | Files、Log、Relog、Expand all、Collapse、Release；Branch、Showall；Make a directory、Rename、Delete、Prune、Attributes；Tag its files、Untag；Terminal here、Usage、Duplicates、Bookmark it、Yank the path |
| 文件窗口中文件之后的空白处 | Filespec、Sort、File display；Tag all、Untag all、Invert tags |
| 查看器 | Search、Next match、Go to line，以及其模式的按键（Wrap、Line numbers、Hex、SQL filter...）、Edit、Yank the path、Close |

每一行在右侧显示其按键，与您的配置一致，因此菜单也是学习按键的一种方式。在此处无法运行的项会被省略：在归档文件内没有 Delete、Move 或 Rename。每一行的执行效果与其按键相同：Delete 仍会先询问。

↑↓ 选择，Enter 执行，Esc 关闭；在菜单外单击只会关闭菜单。

## 标记

| 操作 | 作用 |
|---|---|
| 在文件上按中键或 Ctrl+单击 | 标记或取消标记该文件；光标保持不动 |
| 在目录树的文件夹上执行同样操作 | 选中该文件夹并标记其文件；若其文件已全部标记，则取消标记 |
| 在文件上 Shift+单击 | 标记从光标到该文件之间的所有文件，光标移到该处 |

许多终端把 Shift+单击保留给自身的文本选择；在这些终端中，可用中键或 Ctrl+单击逐个标记文件。

## 焦点、菜单与询问

滚轮移动的是指针下方的列表，而不是获得焦点的列表：目录树下方的小文件窗口可以滚动而不离开目录树。

在 Ctrl 和 Alt 菜单中（按住或用 F4 打开），一个词等同于其字母加 Ctrl 或 Alt：在 Ctrl 菜单中单击 `Copy` 会复制已标记的文件。

当屏幕上有询问、输入框或正在进行的工作时，其后的窗口不接受单击：只有它自己在底部状态栏中的项可以点击。

## 在终端中选择文本

开启鼠标后，终端会把单击发送给 Xylem，因此拖动不再选择屏幕上的文本。拖动时按住 **Shift**（适用于 xterm、GNOME Terminal、Konsole、kitty、WezTerm、Windows Terminal），在 iTerm2 中则按住 **Option**。要复制文件路径，Yank（`Y`）无需鼠标。

## 终端

Xylem 以所有现代终端都支持的 SGR 格式请求单击和按住按键时的移动；从不请求单纯的指针移动，那会白白发送大量事件，在 SSH 上成为负担。内置终端或框架内编辑器中的程序会以它所请求的格式获得鼠标，坐标以其自身面板的边角为准：鼠标事件绝不会到达屏幕的其他部分，也不会到达您的终端。拖出面板的操作仍归该程序，停留在面板边缘。通过 eXecute 或 Edit 运行的程序可能在结束时关闭鼠标；Xylem 在重新获得屏幕时会再次开启它。
