# 配置

## 配置界面 (F12)

按 **F12**（或像在 ZTreeWin 中一样按 Alt+F10；但在 GNOME 桌面上，Alt+F10 通常用于最大化窗口，不会传递给 Xylem）可打开共四页的配置界面：

| 页面 | 选项 |
|---|---|
| 1. 程序与格式 | 编辑器、在 Xylem 框架内打开编辑器、在编辑器中使用 Xylem 主题、用 E 编辑二进制文件、二进制编辑器、帮助语言、默认打开程序 (opener)、日期格式、数字格式、Git 命令、受信任的 Git 文件夹 |
| 2. 显示与排序 | 隐藏文件、初始排序字段与方向、文件窗口中 Enter 的行为、初始显示模式、语法高亮、查看器中的软换行、行号、压缩文件、旧文本的编码与查看器读取的大小限制、图标与字形（Nerd Fonts）、按类型为文件名着色、窗口边框、内置终端的颜色、时钟显示秒 |
| 3. 确认与历史记录 | 退出时确认、删除到回收站、Prune 确认方式、不保存以 `@` 开头的记录、内置终端的独立历史记录 |
| 4. 复制、比较与刷新 | 忽略 2 秒误差、忽略 1 小时误差、自动刷新、Alt+C/Alt+M 的路径起点 |

查看器的大小限制（第 2 页的 **L**）会占用内存和时间：设为 `1024` MiB 时，打开同样大小的普通文本文件大约占用 2.5 GiB 内存，约需 5 秒；由很短的行组成的文件每字节占用更多（见 [查看器](viewer.md)）。

图标与字形（第 2 页的 **M**）需要使用打过 Nerd Fonts 补丁的字体。您并不需要使用某一款特定字体：任何等宽字体均可（例如 Fira Code、JetBrains Mono、Hack、Meslo 或 Cascadia Code），前提是选用其对应的“Nerd Font”版本。Nerd Fonts 会将数千个通用图标字形注入 Unicode 私有区。未打补丁的常规字体（即使是原版 Fira Code）也不包含这些字形，会显示为空白方框（`□`）。安装与使用方法：
- 从 nerdfonts.com 下载任何您喜欢的 Nerd Font 字体，或通过发行版的包管理器安装 Nerd Fonts 字体包。
- 在终端模拟器的字体设置中，将字体更改为已安装的 Nerd Font 字体。

如果开启图标后各列错位，多半是终端把“宽度不明确”（ambiguous width）的字符显示为双宽（这是中文、日文、韩文环境下的常见设置），而 Xylem 将每个图标计为一个字符宽。请将该选项改为单宽，或关闭图标。

按类型为文件名着色（第 2 页的 **N**）会仅根据文件名（不读取内容）为压缩包、图片、音视频、文档、代码和数据分别使用主题中的一种颜色。关闭后列表保持经典外观。窗口边框（**O**）在 nord、gruvbox、slate、graphite、daylight 和 vivid 主题中为圆角，其他主题为直角；`plain` 或 `rounded` 可在所有主题中固定其样式。启动画面（**P**）在 Xylem 打开时以方块字母显示名称两秒；按任意键即可关闭（该键不会执行其他操作），其间会读取起始文件夹。从命令行连接远程机器或容器时不显示，终端小于 58×13 时也不显示。

按选项对应的字母（或 Enter）修改数值，按 PgUp/PgDn 或数字键 1–4 切换页面，按 **F4** 从列表中选择主题（支持实时预览），按 **F3** 保存并应用，按 **Esc** 取消（若有未保存的更改会询问确认）。

## 配置文件

所有配置均保存在 `~/.config/xylem/config.toml`（或 `$XDG_CONFIG_HOME/xylem/`；Windows 上为 `%APPDATA%\xylem\`）中，您也可以手动编辑该文件：配置界面在保存时会保留您的注释。若想生成一份包含所有默认值和详细注释的初始配置文件，可运行：

```bash
mkdir -p ~/.config/xylem && xy --default-config > ~/.config/xylem/config.toml
```

- `theme`：`classic`（XTree 经典蓝）、`dark`、`light`、`mono`（使用终端自身的颜色）、`norton`、`solarized`、`gruvbox`、`nord`、`slate`（Windows Terminal 风格）、`graphite`（macOS 深色风格）、`daylight`（macOS 浅色风格）或 `vivid`（高对比度鲜艳色彩，适合演示与截图）。按 F4 可预览并选择所有主题。
- `[options]`：配置界面中的各项开关与设置。
- `[colors]`：在当前主题基础上单独覆盖个别颜色，可使用颜色名称（如 `"yellow"`）、十六进制 `"#rrggbb"` 或 0 到 255 的色表索引。
- `[keys.any]`、`[keys.tree]`、`[keys.files]`：重新绑定两个窗口通用或单个窗口专用（优先级更高）的按键。例如 `"f3" = "view"`、`"ctrl+r" = "relog"`；设为 `"none"` 可禁用某个按键。帮助中的按键列表（按 **K**）会显示包含您自定义修改在内的当前生效按键。
- `[editors]`：为不同文件类型指定专用编辑器（如 `"*.png *.jpg" = "gimp %f"`、`binary = "hexedit"`）；详见 [编辑](execute.md)。

配置文件中的语法错误不会阻止 Xylem 启动：此时 Xylem 会使用默认设置并在底部状态栏提示错误信息，同时配置界面在错误修复前不会写入文件，以免抹掉您编写的内容。

Xylem 在 0.1 版本之前名为 xt。首次运行时，它会自动将 xt 的配置、历史记录和书签迁移到自己的文件夹中。
