# 配置

## 配置界面 (F12)

按 **F12**（或按 Alt+F10；但在 GNOME 桌面上，Alt+F10 通常用于最大化窗口，不会传递给 Xylem）可打开共五页的配置界面：

| 页面 | 选项 |
|---|---|
| 1. 程序与格式 | 编辑器、在 Xylem 框架内打开编辑器、在编辑器中使用 Xylem 主题、用 E 编辑二进制文件、二进制编辑器、帮助语言、默认打开程序 (opener)、日期格式、数字格式、Git 命令、受信任的 Git 文件夹 |
| 2. 显示与排序 | 隐藏文件、初始排序字段与方向、文件窗口中 Enter 的行为、初始显示模式、语法高亮、查看器中的软换行、行号、压缩文件、旧文本的编码与查看器读取的大小限制、图标与字形（Nerd Fonts）、按类型为文件名着色、窗口边框、内置终端的颜色、时钟显示秒、[鼠标](mouse.md) |
| 3. 确认与历史记录 | 退出时确认、删除到回收站、Prune 确认方式、不保存以 `@` 开头的记录、内置终端的独立历史记录、[模糊查找中 Alt+T 标记全部匹配项](#tagging-every-match-of-the-fuzzy-find)、[检查新版本](#new-versions) |
| 4. 复制、比较与刷新 | 忽略 2 秒误差、忽略 1 小时误差、自动刷新、Alt+C/Alt+M 的路径起点、不纳入索引的文件和文件夹 |
| 5. 阅读（电子书） | 文本栏的宽度、段落按书籍样式或分块排列、两端对齐、计算剩余时间所用的阅读速度、[阅读时间](#reading-time)、无按键多少分钟后停止计时、保留书名以列出读过的书 |

查看器的大小限制（第 2 页的 **L**）会占用内存和时间：设为 `1024` MiB 时，打开同样大小的普通文本文件大约占用 2.5 GiB 内存，约需 5 秒；由很短的行组成的文件每字节占用更多（见 [查看器](viewer.md)）。

图标与字形（第 2 页的 **M**）需要使用打过 Nerd Fonts 补丁的字体。您并不需要使用某一款特定字体：任何等宽字体均可（例如 Fira Code、JetBrains Mono、Hack、Meslo 或 Cascadia Code），前提是选用其对应的“Nerd Font”版本。Nerd Fonts 会将数千个通用图标字形注入 Unicode 私有区。未打补丁的常规字体（即使是原版 Fira Code）也不包含这些字形，会显示为空白方框（`□`）。安装与使用方法：
- 从 nerdfonts.com 下载任何您喜欢的 Nerd Font 字体，或通过发行版的包管理器安装 Nerd Fonts 字体包。
- 在终端模拟器的字体设置中，将字体更改为已安装的 Nerd Font 字体。

如果开启图标后各列错位，多半是终端把“宽度不明确”（ambiguous width）的字符显示为双宽（这是中文、日文、韩文环境下的常见设置），而 Xylem 将每个图标计为一个字符宽。请将该选项改为单宽，或关闭图标。

按类型为文件名着色（第 2 页的 **N**）会仅根据文件名（不读取内容）为归档文件、图片、音视频、文档、代码和数据分别使用主题中的一种颜色。关闭后列表保持经典外观。窗口边框（**O**）在 nord、gruvbox、slate、graphite、daylight 和 vivid 主题中为圆角，其他主题为直角；`plain` 或 `rounded` 可在所有主题中固定其样式。启动画面（**P**）在 Xylem 打开时以方块字母显示名称两秒；按任意键即可关闭（该键不会执行其他操作），其间会读取起始文件夹。从命令行连接远程主机或容器时不显示，终端小于 58×13 时也不显示。

按选项对应的字母（或 Enter）修改数值，按 PgUp/PgDn 或数字键 1–5 切换页面，按 **F4** 从列表中选择主题（支持实时预览），按 **F3** 保存并应用，按 **Esc** 取消（若有未保存的更改会询问确认）。

### 模糊查找中标记全部匹配项

在模糊查找（`|`）中，**Alt+T** 标记列表中的结果。列表保留最匹配的 500 项，而一次搜索可能匹配多得多的项：在大型目录树中，`f` 可能匹配十万个文件。默认情况下，Alt+T 只标记列表中的这 500 项；匹配项更多时，列表下方的一行会说明这一点，并给出本选项的名称。

开启 **Alt+T in the fuzzy find tags every match**（第 3 页的 **F**，文件中为 `fuzzy_tag_all = true`）后，Alt+T 会标记所有匹配项，包括您从未看到的那些。此时列表下方的一行总是会说明有多少匹配项不在列表中。

此选项默认关闭，因为标记会延续到您接下来的操作。Ctrl+C、Ctrl+M、Ctrl+D 和批处理会作用于所有已标记的文件，而不只是您看到的那些。一次您只扫了一眼的搜索标记了数千个文件，接着又把它们删除，就是数千个文件没了。只有在操作前会检查标记了哪些文件时，才开启此选项：

- 统计信息面板显示已标记文件的数量及其大小；
- 目录树中的 **Ctrl+S** 列出整个目录树中已标记的文件（只含已标记文件的 Showall）；
- 文件窗口中的 **Ctrl+V** 逐个查看这些文件。

### 新版本

Xylem 首次启动时，在启动画面消失后会询问：*Look for a new version of Xylem once a day?* **Y** 表示同意，**N** 表示不同意，答案保存在配置文件中（`check_updates`）。**Esc** 不保存任何内容，下次启动时会再次询问。之后可用第 3 页的 **G** 更改答案。

开启后，Xylem 每天向网站（`https://andrelnfernandes.github.io/xylem/latest.txt`）请求一次一行内容：最新版本的版本号。它通过系统的 `curl` 在后台完成，只使用 HTTPS，最多五秒；没有网络或没有 `curl` 时，不会给出任何提示，第二天再试。请求只携带 `xylem/` 和您正在运行的版本；与任何访问一样，网站能看到您的 IP 地址。不会下载或安装任何内容：有更新的版本时，顶部一行会在时钟旁显示 `0.10.0 is out`，并有一条消息给出发布页面的地址。请按您安装时的方式更新：`.deb` 或 `.rpm` 用包管理器，其他情况下用新的归档文件。

来自网站的回答被视为恶意内容：任何不是三个数字的内容，例如酒店 Wi-Fi 的页面，都会被忽略。上次检查的日期和找到的版本保存在状态文件夹中（`~/.local/state/xylem/update-check`）。

环境变量 `XYLEM_CHECK_UPDATES=0`（或 `1`）会直接给出答案而不询问，并优先于配置文件，适用于在多台机器上安装的情况。不带 `update-check` 功能构建的版本（`cargo build --no-default-features --features index`），例如某个发行版可能制作的版本，没有这个询问、检查和选项。

### 阅读时间

查看器能读取 EPUB 和 FB2 [电子书](viewer.md#ebooks)。第 5 页设置正文的排版方式，以及 Xylem 是否保存您的阅读时间。

**Keep the time spent reading**（**E**，文件中为 `reading_stats = true`）默认关闭。开启后，Xylem 会为查看器中用 `R` 记住的每本书保存：

- 阅读时间和阅读次数：停顿超过 30 分钟就算新的一次；
- 读到的最远位置、第一天和最后一天阅读的日期，以及是否读完；
- 阅读速度，以每分钟字数计。只计算向前阅读的页面，并且在该页至少停留 5 秒，因此跳转、回退和略读都不算。累计测量 10 分钟后，页脚会用这本书自己的速度计算剩余时间，而不是用本页设置的速度（**D**）。

只有在阅读时才计时：从一次按键到下一次按键，前提是两者之间不超过 **F** 分钟（默认 3 分钟）。更长的停顿会停止计时，且该停顿不计入。Autoview（F7）和报告（`I`）从不计时。

所有这些数据都只保存在您的电脑上，位于 `~/.local/state/xylem/reading.toml`（或 `$XDG_STATE_HOME/xylem/`），只有您可以读取。一本书以它自称的身份和大小的哈希值加上一些数字来保存：不保存文件名、位置和书名。开启 **G**（`reading_titles = true`）后，也会保存书名和作者，此时任何一本书的报告都会在“Your books”下列出所有读过的书。

关闭 **G** 并保存（F3）会立即删除已保存的书名。关闭 **E** 并保存时，会询问是否删除所有书的阅读时间；如果不删除，这些数据会留在文件中，但不显示。无论哪种情况，用 `R` 记住的位置都会保留；对一本书按 `R` 会忘记它。

## 配置文件

所有配置均保存在 `~/.config/xylem/config.toml`（或 `$XDG_CONFIG_HOME/xylem/`；Windows 上为 `%APPDATA%\xylem\`）中，您也可以手动编辑该文件：配置界面在保存时会保留您的注释。若想生成一份包含所有默认值和详细注释的初始配置文件，可运行：

```bash
mkdir -p ~/.config/xylem && xy --default-config > ~/.config/xylem/config.toml
```

- `theme`：`classic`（蓝底白字与黄字）、`dark`、`light`、`mono`（使用终端自身的颜色）、`norton`、`solarized`、`gruvbox`、`nord`、`slate`（Windows Terminal 风格）、`graphite`（macOS 深色风格）、`daylight`（macOS 浅色风格）或 `vivid`（高对比度鲜艳色彩，适合演示与截图）。按 F4 可预览并选择所有主题。
- `[options]`：配置界面中的各项开关与设置，以及几项只在文件中提供的选项：`scan_max_files`（10000），即[扫描](views.md#scan)最多读取内容的文件数。
- `[colors]`：在当前主题基础上单独覆盖个别颜色，可使用颜色名称（如 `"yellow"`）、十六进制 `"#rrggbb"` 或 0 到 255 的色表索引。
- `[keys.any]`、`[keys.tree]`、`[keys.files]`：重新绑定两个窗口通用或单个窗口专用（优先级更高）的按键。例如 `"f3" = "view"`、`"ctrl+r" = "relog"`；设为 `"none"` 可禁用某个按键。帮助中的按键列表（按 **K**）会显示包含您自定义修改在内的当前生效按键。
- `[editors]`：为不同文件类型指定专用编辑器（如 `"*.png *.jpg" = "gimp %f"`、`binary = "hexedit"`）；详见 [编辑](execute.md)。

配置文件中的语法错误不会阻止 Xylem 启动：此时 Xylem 会使用默认设置并在底部状态栏提示错误信息，同时配置界面在错误修复前不会写入文件，以免抹掉您编写的内容。

Xylem 在 0.1 版本之前名为 xt。首次运行时，它会自动将 xt 的配置、历史记录和书签迁移到自己的文件夹中。
