# 重命名与批量重命名

`R` 重命名光标下的文件（在目录树中则是目录）：直接输入新名称即可。若名称已存在则会被拒绝。

## 批量重命名 (Ctrl+R)

使用掩码重命名所有已标记的文件，并按列表顺序编号：

- **通配符：** `*.jpg`（修改扩展名）、`new_*.*`、`*_old.*`、`???.*`（保留指定数量的字符）。`*.*` 保持原名不变；`*.` 移除扩展名。
- **查找与替换：** `s/foo/bar/` 将所有的 `foo` 替换为 `bar`；`s/foo/bar/i` 忽略大小写。
- **计数器：** `%d`、`%02d`、`%03d`、`%04d`、`<#>`、`<01>`、`<001>`、`<0001>` 为文件编号（1、01、001...）：如 `photo_<001>.*` 会生成 `photo_001.jpg`、`photo_002.jpg` 等。
- **大小写：** `<lower>`、`<upper>`、`<title>`（也可仅用于主文件名或扩展名部分，如 `*.<lower>`），或者在提示行中按 **F2** 将结果在全小写、全大写和首字母大写之间循环切换。

如果掩码会导致两个文件重名，则不会执行任何重命名。当新名称与列表中尚未轮到重命名的某个文件冲突时，或目标文件已存在时，Xylem 会在覆盖前询问，与 [复制与移动](copy-move.md) 相同。
