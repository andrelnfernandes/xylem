# 重复文件 (Alt+Y)

查找内容相同的文件（无论名称和文件夹如何），以及副本浪费的空间。**Alt+Y** 在当前目录的分支中查找；在磁盘用量视图中按 **D** 则在所列文件夹中查找。

```
── 3 × 1.2 GiB (2.4 GiB to free) ──────────────────────
     1.2 GiB  2023-08-14  Backups/phone-2023.zip
 T   1.2 GiB  2023-08-14  Downloads/phone-2023.zip
 T   1.2 GiB  2023-08-14  Old/phone-2023 (1).zip
── 2 × 850.0 MiB (850.0 MiB to free) ──────────────────
     850.0 MiB  2021-12-25  Videos/christmas.mp4
 T   850.0 MiB  2022-01-03  WhatsApp/VID-20211225.mp4
```

释放空间最多的排在最前。除非您要求，否则不会标记任何内容，并且每组始终保留一个副本：Xylem 不允许标记最后一个。

## 选择要移除的内容

| 按键 | 作用 |
|---|---|
| ↑ ↓ PgUp PgDn Home End | 移动 |
| `T` 或空格 | 标记或取消标记该副本 |
| `K` | 保留此副本：标记同组其他副本 |
| `A` | 在每组中标记除一个以外的全部；再按 `A` 更改保留哪一个：最旧、最新、路径最短 |
| `F` | 在每个有副本位于此副本所在文件夹的组中，保留那一个 |
| `U` | 取消全部标记 |
| `D`、Del 或 Ctrl+D | 删除已标记的，与 Delete 命令相同（`delete_to_trash` 开启时进入回收站） |
| `M` 或 Ctrl+M | 移动已标记的文件 |
| `G` | 文件或整个文件夹 |
| `V` 或 Enter | 查看文件 |
| `E` | 将列表写入文件（绝不覆盖已有文件）：大小、日期、标记和路径，各组之间空一行 |
| `\` | 关闭视图，目录树定位到该文件夹 |
| F3 | 重新读取文件夹并再次比较 |
| Esc 或 Alt+Y | 关闭 |

删除或移动之前，会再次检查每一组：如果某个副本在分析后发生了变化，或者本应保留的副本已不存在，则不会触碰该组的任何内容，底部状态栏会说明。

## 整个文件夹

整份重复的备份占用空间最多，而长长的文件列表会掩盖这一点。**G** 显示内容完全相同的文件夹：相同的名称、每个文件（无论大小）相同的内容，以及指向相同位置的相同链接。只列出最上层的文件夹，不列出其中的子文件夹。

如果文件夹中有未比较的内容（无法读取的文件夹、挂载在其中的其他磁盘、特殊文件或被忽略的文件夹，见下文），它绝不会被视为副本。同一仓库的两个克隆拥有相同的文件，但它们的 `.git` 可能保存着不同的工作。

## 如何比较文件

大小来自内存。只读取大小与其他文件相同的文件：先读两端，再分段读中间；一旦组内文件出现差异就立即拆分该组，因此不同的文件不会被读到末尾。比较使用 SHA-256，在后台进行：底部状态栏显示进度，Esc 可取消。

以下内容不在列表中：

- 小于 `duplicates_min_size`（默认 1 KiB）的文件和空文件；
- 链接和特殊文件，它们不会被跟随；
- 同一文件的其他硬链接：它们已经共享空间，删除其中一个不会释放任何空间；
- 挂载在分支内的其他磁盘；
- `duplicates_ignore` 中的文件夹（默认为 `.git` 和 `node_modules`）。

自读取目录树以来发生变化的文件或无法读取的文件不参与比较；底部一行会显示数量。F3 重新读取全部内容。

在网络文件夹（NFS、SMB、sshfs...）中，会先询问要读取的总量。在 [远程主机](remote.md) 上也是如此：文件通过 SSH 在远程读取，并且在删除任何内容之前会像本机一样再次检查。有两点不同：SFTP 不提供 inode，因此指向同一文件的两个硬链接会显示为一对（删除其中一个既不释放空间也不丢失内容）；分支内挂载的其他磁盘会根据其文件系统被排除，这需要 OpenSSH 的 `statvfs` 扩展。在压缩包内，重复文件功能不可用。

## 云端 (rclone)

在 `rclone mount` 挂载的文件夹中，读取文件就意味着下载它。因此 Xylem 向 rclone 获取服务已保存的哈希值（`rclone lsjson --hash`），不下载任何内容：整个 Drive 只需几分钟。它使用服务提供的最强哈希（SHA-256、SHA-1、MD5...）并结合大小，rclone 必须在 PATH 中。否则，或远程不提供哈希值时（例如加密的远程），Xylem 会说明原因，并在通过挂载读取文件之前询问，同时显示将要下载的总量。

整个文件夹只在本地磁盘上比较。

在 Google Drive 上：

- 同时位于两个文件夹中的文件或快捷方式是同一个文件：绝不会与自身配对。
- Docs、表格和幻灯片没有哈希值：底部一行会显示有多少被排除。
- 他人与您共享的内容以 `s` 显示，“除一个以外全部标记”不会触碰它：删除它不会释放您的存储空间。
- 同一文件夹中同名的两个文件无法通过挂载区分；底部一行会建议使用 `rclone dedupe`。
- 删除会进入 Drive 回收站，在清空之前仍占用空间。Xylem 不会清空它，因为那会带走其中的所有内容；它会显示命令：`rclone cleanup gdrive:`。

服务提供的哈希值是基于信任接受的。MD5 可以被故意伪造：对于他人可能放入的文件，请在删除前先比较。
