# Treespec 与 Log

## Treespec（`\` 或 `/`）

打开带有当前路径的提示行。随着您的输入，目录树光标会实时跳到以所输内容开头的第一个目录（不区分大小写）：

- `/` 或 `\` 补全当前目录名并向下一层；
- Tab 和 Shift+Tab 补全并在同一层级的下一个或上一个目录之间切换；
- Backspace 退回上一层；
- Enter 确认，Esc 返回原位；
- ↑ 调出之前用过的路径（会在多次运行之间保存）。

若确认的路径不在当前目录树内，则会像 Log 一样打开该路径。在 Branch 和 Showall 视图中，按 `\` 会直接跳转到所选文件所在的目录，并将该文件高亮显示。

## Log (L)

在窗口中打开另一个目录并替换当前目录树（若该目录已在当前目录树内，则只是将光标移过去）。输入形如 `user@host:` 的地址可打开 [远程主机](remote.md)。路径可以是绝对路径、相对于当前目录的路径，或以 `~` 开头；按 **F2** 可 [从目录树中选择](picker.md)，按 ↑ 调出历史记录。新打开的窗口会保留当前的 [排序顺序](sort.md) 和显示模式。

提示行打开时为空。按 ↑ 可依次调出之前用过的位置，最近的在前：包括用 Log 打开过的目录，以及复制或移动文件时用过的目标文件夹。

另请参阅：[目录树窗口](tree.md)、[书签](bookmarks.md)。
