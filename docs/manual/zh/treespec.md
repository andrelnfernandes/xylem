# Treespec 与 Log

## Treespec（`\` 或 `/`）

打开带有当前路径的提示行。随着您的输入，目录树光标会实时跳到以所输内容开头的第一个目录（不区分大小写）：

- `/` 或 `\` 补全当前目录名并向下一层；
- Tab 和 Shift+Tab 补全并在同一层级的下一个或上一个目录之间切换；
- Backspace 退回上一层；
- Ctrl+← 去掉路径中的最后一个文件夹（`~/projects/xylem/docs/` 变为 `~/projects/xylem/`，光标停在 `xylem` 上），Ctrl+→ 把去掉的文件夹逐个恢复；输入其他内容则开始一条新路径；
- Enter 确认，Esc 返回原位；
- ↑ 以[列表](execute.md#历史记录)形式打开之前用过的路径（会在多次运行之间保存）。

若确认的路径不在当前目录树内，则会像 Log 一样打开该路径。在 Branch 和 Showall 视图中，按 `\` 会直接跳转到所选文件所在的目录，并将该文件高亮显示。

## Log (L)

在窗口中打开另一个目录并替换当前目录树（若该目录已在当前目录树内，则只是将光标移过去）。输入形如 `user@host:` 的地址可打开 [远程主机](remote.md)。路径可以是绝对路径、相对于当前目录的路径，或以 `~` 开头；按 **F2** 可 [从目录树中选择](picker.md)，按 ↑ 列出之前用过的路径。新打开的窗口会保留当前的 [排序顺序](sort.md) 和显示模式。

按 **Alt+L** 可立即把光标所在的目录设为目录树的根：用 `L` 前往目录树内的目录只会移动光标，再按 Alt+L 即可把目录树缩小到该目录。在文件窗口中，取当前显示的目录（在 Branch 和 Showall 中，取所选文件所在的目录）。窗口会在该处重新打开，因此已读取的内容和标记都会丢失；`L ..` 可重新打开上一级目录。在归档文件内和远程主机上不可用。

提示行打开时为空。按 ↑ 打开之前用过的位置的[列表](execute.md#历史记录)，最近的在最下方：包括用 Log 打开过的目录，以及复制或移动文件时用过的目标文件夹。输入文字可过滤列表，Enter 把某个位置放入提示行，Del 把它从列表中移除。

**F11** 按名称将 [书签](bookmarks.md) 填入提示行，无需手动输入远程主机或容器的地址。

另请参阅：[目录树窗口](tree.md)、[书签](bookmarks.md)。
