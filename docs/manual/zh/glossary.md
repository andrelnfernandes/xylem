# 术语

以下词汇源自 XTree 与 ZTreeWin。菜单与本手册均按下述含义使用它们。

| 词汇 | 含义 |
|---|---|
| Log | 将目录载入内存：包括其中的文件和子目录名称。`→` 或 `+` 载入单个目录，`*` 载入整个分支。`L` (Log) 也是将另一个目录打开为目录树的命令。[目录树窗口](tree.md) |
| Logged | 已载入内存。只有已载入的文件才会出现在列表中、计入统计信息中，以及可以被标记。 |
| Not logged | 名称已知但尚未读取其内容的目录。目录树中用 `?` 标识。 |
| Release | 用 `-` 从内存中释放分支。其中的文件会从列表中移除并失去标记。磁盘上的内容不会发生任何改变。 |
| Relog | 用 F3 从磁盘重新读取目录。 |
| Branch | 一个目录及其下方的所有内容。`B` 在一个列表中列出分支的所有文件。 |
| Showall | 窗口中所有已载入文件的列表，按 `S` 打开。 |
| Tag | 文件上的标记（`■`）。Ctrl 系列命令作用于已标记的文件。标记保存在内存中，在释放或退出时丢失。[标记](tagging.md) |
| Filespec | 窗口显示哪些文件的过滤器，按名称、日期和大小筛选。按 `F` 设置。[Filespec](filespec.md) |
| Treespec | 输入路径以移动目录树光标。按 `\` 或 `/` 打开。[Treespec 与 Log](treespec.md) |
| Window | 一个目录树及其文件窗口。按 F8 可以在旁边打开第二个窗口。[分屏](split.md) |
| Root | 目录树顶部的目录。`L` 更改它，Alt+L 将光标下的目录设为根目录。 |
| Matching | 符合 Filespec 过滤条件的已载入文件。 |
| Mask | 为每个文件生成名称或单行内容的掩码模式：`*.bak`、`photo_<001>.*`。用于重命名和批处理。[重命名](rename.md) |
| Batch | Ctrl+B：为每个已标记的文件（或查看器中表格的每条记录）写入一行的文件。[批处理](execute.md) |
| Prune | Alt+P：删除目录及其包含的所有内容。[删除](delete.md) |
| Oops | 从回收站恢复最近删除的内容。目录树中为 `O`，两个窗口中均为 Ctrl+Z。 |
| Yank | `Y`：将路径复制到剪贴板。 |
| Autoview | F7：在文件列表旁显示光标下文件内容的窗口模式。 |
| eXecute | `X`：运行 shell 命令，`%f` 代表文件，`%t` 代表已标记的文件。[执行](execute.md) |
| Avail | 目录树中的 `A`：已挂载的文件系统及其可用空间。 |

另请参阅：[Xylem 是什么](overview.md)、[菜单](menus.md)。
