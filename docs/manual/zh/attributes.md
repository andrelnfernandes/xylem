# 权限与日期

## 权限 (A)

`A` 以八进制（如 `644`、`755`）修改光标下文件的权限（Ctrl+A：修改已标记文件的权限）。

在 Windows 上，`A` 会像 ZTreeWin 一样编辑 R、H、S 和 A 属性：`RA` 精确设置为这些属性，`+H -A` 单独开启或关闭某些属性。文件列表中会将它们显示为 `r-sa`。详见 [Windows](windows.md)。

## 修改日期 (N)

`N` 修改文件或目录的修改日期（Ctrl+N：修改已标记文件的日期）。提示行会预先填入按您配置格式显示的当前日期；也接受 `now` 和 `today`。如果只输入日期（不含 `HH:MM`），每个文件会保留其原有的具体时间。符号链接会被跳过（否则会改变其指向的目标文件的日期）。

日期格式在 [配置](configuration.md) 的第 1 页中设置。
