# 功能键与符号

这些按键位于 DIR 和 FILE 菜单的最后一行，或者因为仅用于移动光标而未在菜单中列出。它们不能与 F9 菜单组合使用：按 F9 之后，只有下一个按下的字母才会附带 Ctrl 或 Alt。

## 功能键

| 按键 | 窗口 | 功能说明 |
|---|---|---|
| F1 | 两者 | 打开当前屏幕所处状态的相应帮助。Alt+H 功能相同。[终端与按键](terminals.md) |
| F2 | 两者 | 重新读取目录，同 F3。在询问文件夹的提示框中，打开目录树以[选择文件夹](picker.md)。 |
| F3 | 两者 | 从磁盘重新读取目录。 |
| F5 | 文件 | 将光标下的文件打包成归档文件。Ctrl+F5：打包已标记的文件。Alt+F5：打开归档文件。[归档文件](archives.md) |
| F7 | 文件 | Autoview：在列表旁显示光标下文件的内容。[文件窗口](files.md) |
| F8 | 两者 | 在旁边打开第二个窗口，或关闭它。[分屏](split.md) |
| F9 | 两者 | 依次显示 CTRL 菜单、ALT 菜单，然后返回平时菜单。[菜单](menus.md) |
| F10 | 两者 | 退出，同 `Q`。 |
| F11 | 两者 | 打开书签管理器，同 Alt+B。Ctrl+F11 保存当前目录。[书签](bookmarks.md) |
| F12 | 两者 | 打开配置。[配置](configuration.md) |

## 符号

| 按键 | 窗口 | 功能说明 |
|---|---|---|
| `*` | 目录树 | 载入光标下的目录及其下方的全部内容。按 Esc 取消。 |
| `+` 或 → | 目录树 | 载入目录并显示其子目录。 |
| `-` | 目录树 | 从内存中释放该分支。 |
| ← | 目录树 | 折叠该目录，或返回其父目录。 |
| `?` | 两者 | 显示当前窗口、磁盘、机器与 Xylem 的统计信息。[信息](info.md) |
| `\` 或 `/` | 两者 | Treespec：输入路径，目录树光标随之移动。在 Branch 或 Showall 视图中，跳转到光标所在文件的目录。[Treespec 与 Log](treespec.md) |
| `'` | 两者 | 跳转到书签：接着按下其对应的按键。 |

## 移动

| 按键 | 窗口 | 功能说明 |
|---|---|---|
| ↑ ↓ PgUp PgDn Home End | 两者 | 移动光标。 |
| 空格 (Space) | 两者 | 向下移动一行。 |
| Enter | 目录树 | 进入文件窗口。 |
| Enter | 文件 | 返回目录树。当启用 `enter_views` 时，查看文件。 |
| Esc | 文件 | 返回目录树，定位到光标所在文件的目录。 |
| Esc | 目录树 | 在归档文件内部时，关闭归档。 |
| Tab | 两者 | 在分屏模式下切换到另一个窗口。否则同 Enter。 |
| Backspace | 两者 | 返回父目录。 |
| Shift+字母, 0–9 | 两者 | 跳转到以此字符开头的下一个目录或文件。 |
| ← → | 文件 | 向上/向下翻页。在分栏显示模式下，移至上一个/下一个文件。 |

## 修改按键映射

`config.toml` 中的 `[keys.any]`、`[keys.tree]` 与 `[keys.files]` 可以将按键绑定到其他命令或 `none`。在帮助中按 **K** 可列出当前生效的按键（包含这些自定义修改）。参见[配置](configuration.md)。

另请参阅：[DIR 和 FILE 菜单](commands.md)、[Ctrl 菜单](commands-ctrl.md)、[Alt 菜单](commands-alt.md)。
