# 表格：电子表格、CSV 与数据库

有些文件以网格而不是文本形式打开。Xylem 根据扩展名判断，且仅限本磁盘上未压缩的文件：远程主机上或归档文件内的文件显示为普通内容，并给出提示 `Tables are shown only for files on this disk`。

| 格式 | 扩展名 | 列名 |
|---|---|---|
| CSV、TSV | `.csv` `.tsv` `.tab` | 第一行（至少一半内容不是数字时）；否则为 A、B、C... |
| JSON Lines | `.jsonl` `.ndjson` | 对象的键 |
| 电子表格 | `.xlsx` `.xls` `.xlsb` `.ods` | A、B、C...（第一行与其他行相同） |
| dBase、Clipper、FoxPro | `.dbf`，以及其备注文件 `.dbt` | 字段名 |
| SQLite | `.db` `.sqlite` `.sqlite3` | 数据表的列 |
| Parquet | `.parquet` | 文件的列 |

CSV 的分隔符（逗号、分号、制表符或竖线）根据文件开头自动检测。

| 按键 | 功能 |
|---|---|
| ↑ ↓ | 上一行或下一行 |
| ← → | 上一列或下一列 |
| PgUp PgDn | 向上或向下翻一页 |
| Home End | 第一列或最后一列 |
| Ctrl+Home Ctrl+End | 第一行或最后一行；有筛选时，指筛选保留的行 |
| `[` `]` | 电子表格的上一个或下一个工作表，或 SQLite 数据库的上一个或下一个数据表，循环切换；这会清除筛选 |
| `Tab` | 工作表或数据表列表：输入名称的一部分可缩小列表，Enter 打开，Esc 返回；打开另一个会清除筛选。在数据库中，视图排在数据表之后，并标有 `(view)` |
| `g` 或 `:` | 按文件中的行号跳转；如果该行被筛选隐藏，则跳到下一个保留的行 |
| `\` 或 `&` | SQL 筛选 |
| `m` 或 Insert | 标记或取消标记光标所在记录并移到下一条；之后 **Ctrl+B** 只写入已标记的记录 |
| `M` | 清除标记 |
| `i` | 表的结构：文件对每一列的说明（见下文） |
| Enter | 以表单形式显示光标所在的记录，每行一个字段：↑ ↓ 选择字段，← → 转到上一条或下一条记录，`c` 复制整条记录（`名称 : 值`，每个字段一行），`y` 复制该字段的值，可粘贴到编辑器或终端；Esc 返回。复制的内容就是屏幕上显示的内容：控制字符和文字方向字符（包括换行）都显示为 `·`，因此粘贴到终端不会执行任何命令。在表格之外，Enter 关闭查看器 |
| `T` | 切换到文件的文本，再切换回来 |
| `H` | 从表格到文本，然后到十六进制，再回到表格 |

有多个工作表或数据表时，边框显示 `TABLE [2/5: 名称]`；底部一行显示光标位置：`Cell B7 (Row 7 of 120)`。筛选时，各行保留其在文件中的行号，这一行还会显示是第几个匹配：`Cell A13 (Row 13 of 31, match 2 of 8)`。网格的最后一行显示单元格的完整内容和当前筛选。搜索（`F`、`B`、`/`）不会查看网格内容，在这里什么也找不到；它在文本模式下可用。

标记在筛选下仍然保留，Batch 写入已标记且被筛选保留的记录。标记属于当前打开的工作表或表，切换后会丢失。如果标记后文件发生变化，Batch 会拒绝执行，因为这些位置可能已是其他记录。

## 结构

`i` 在表格上方按顺序列出各列以及文件对每一列的说明，就像 dBase 和 Clipper 中的 `DISPLAY STRUCTURE`。方向键、PgUp、PgDn、Home 和 End 用于滚动；Esc、Enter 或 `i` 关闭。

| 格式 | 显示内容 |
|---|---|
| dBase、Clipper、FoxPro | 名称、类型（`C` 字符、`N` 数值、`D` 日期、`L` 逻辑、`M` 备注、`F` 浮点、`I` 整数、`B` 双精度、`Y` 货币、`T` 日期时间）、宽度和小数位数；上方是文件头中记录的记录数和最后更新日期，以及一条记录的长度 |
| SQLite | 每一列声明的类型、`Not null`、默认值以及在主键中的位置；上方说明是表还是视图，以及它的索引和索引包含的列（最多 32 个）。视图显示它给出的列；完整查询显示结果的列，直接来自表中某列的会显示其类型 |
| Parquet | 每一列的 Arrow 类型以及是否允许空值；上方是文件声明的行数和行组数，以及写入该文件的程序 |
| CSV、JSON Lines、电子表格 | 这些格式不声明类型：显示已读取的行在每一列中出现的值（整数、小数、逻辑、文本、空）以及最宽的值 |

名称、类型和默认值来自文件，和单元格一样经过清理：控制字符和文字方向字符显示为 `·`。文件头自相矛盾的 `.dbf` 在小数位数处显示 `?`。

## SQL 筛选

`\` 或 `&` 会要求输入条件，写法类似 SQL 的 `WHERE`（`WHERE` 一词可省略），并只显示满足条件的行。提示行中预先填入当前筛选；留空即可重新显示所有行。提示信息会显示 `Filter matched N rows` 或 `SQL error: ...`；出错后，之前的筛选仍然有效。

```
age >= 30 AND name LIKE 'Ali%'
WHERE status IN ('open', 'late') OR total > 1000.50
NOT (city = 'Rio' OR city IS NULL)
B ILIKE '%silva%'
```

| 运算符 | 功能 |
|---|---|
| `=` `!=` `<>` `<` `<=` `>` `>=` | 比较 |
| `AND` `OR` `NOT` 和括号 | 组合条件（`AND` 优先于 `OR`） |
| `LIKE` `ILIKE` | 匹配模式，`%` 表示任意文本，`_` 表示一个字符；`ILIKE` 忽略大小写 |
| `IN (...)` `NOT IN (...)` | 在或不在列表中 |
| `IS NULL` `IS NOT NULL` | 单元格为空或不为空 |

关键字不区分大小写。

- **列：** 列名（不区分大小写，不加引号），或其字母 `A` 到 `Z`。名称含空格或符号时，可用字母引用。不存在的列视为空，不会报错。
- **值：** 单引号或双引号中的文本（其中的引号写作 `\'`）、数字、`TRUE`、`FALSE` 和 `NULL`。引号中的内容始终是文本，绝不是列。
- **单元格：** 类型取决于单元格的内容形式。空单元格为 `NULL`，`true` 和 `false` 是布尔值，数字就是数字，其余为文本。因此请写 `code = 7`，而不是 `code = '7'`：文本和数字永不相等，内容为 `007` 的单元格就是数字 7。文本比较区分大小写。
- **长度：** 筛选条件最多 1024 字节、128 个词项。

## 在数据库中运行完整查询

在 SQLite 数据库中，同一个提示行也接受以 `SELECT` 或 `WITH` 开头的完整查询，可使用 SQLite 的全部功能：`JOIN`、`GROUP BY`、`ORDER BY`、函数。

```
SELECT c.name, sum(o.price) FROM customers c JOIN orders o ON o.code = c.code GROUP BY c.name
```

边框显示 `QUERY:`，网格显示结果。之后输入条件可筛选这些行，**Ctrl+B** 会写入查询给出的全部结果。提示行留空先清除筛选，再回到数据表；`Tab`、`[` 和 `]` 也会回到数据表。查询只能读取，且一次一条：其他内容都会被拒绝，出错时屏幕保持原样。下面的限制同样适用，因此较慢的查询在 3 秒时停止并显示已得到的行；Batch 没有这个限制。Xylem 不会修改数据库：`UPDATE`、`DELETE` 等会收到说明此事的消息。要修改数据库，请使用其他程序：在文件窗口按 `O` 用 `opener` 设置的程序打开，在 `[editors]` 中写 `'*.db' = 'sqlite3 %f'` 可让 `E` 用 `sqlite3` 打开。

## 大表格

用 **V** 打开时，以下表格没有行数限制：CSV 或 TSV 文件、JSON Lines 文件、dBase 文件（`.dbf`），以及 SQLite 数据库中的表或视图，或在其中输入的查询。表格只保留光标附近的行，最多 2,000 行、32 MiB 文本，其余的随光标移动从文件中读取，不会卡住屏幕：尚未读取的行会短暂显示为 `…`。

- **总行数** 在统计过程中显示：`Row 1 of 2,000+ (counting…)`，然后是 `Row 1 of 8,412,903`。**Ctrl+End** 跳到最后一行，`g` 跳到任意一行；统计结束前，用 `g` 跳到尚未统计到的位置会提示统计还没到那里。
- **筛选**（`&`）在后台遍历整个表格。表格下方一行显示进度，`1,203 matches so far, row 2,300,000 of 8,412,903`，找到的行陆续显示。最多保留 1,000,000 个匹配，此时显示 `first 1,000,000 matches`。
- **Esc** 停止统计或筛选，保留已找到的内容；再按一次 Esc 关闭查看器。
- 列宽取自开头的若干行，屏幕上出现更宽的行时该列会变宽。JSON Lines 文件在统计过程中也可能增加列，因为某个键可能在后面才第一次出现。
- **CSV、TSV 和 JSON Lines** 在统计时从头到尾读取一遍，Xylem 记下每第 256 行的起始位置，因此跳到任意一行最多只需读取 255 行。这些记录仅保存在内存中，每 256 行约 8 字节，关闭查看器后即丢弃。引号内含换行的 CSV 记录仍算一行。超过 16 MiB 的 CSV 记录会停止读取，超过 512 KiB 的 JSON Lines 行会被跳过。
- **dBase 记录** 大小全都相同，因此 Xylem 可以直接跳到任意一条。统计时只检查每条记录是否已删除，因为已删除的记录不算一行：Xylem 以同样的方式记下每第 256 行的位置。
- **文件在打开期间发生变化时**（变大、变小或被替换），Xylem 记下的信息不再有效：不再从中读取任何内容，标题栏显示 `(the file changed: R reloads)`。按 **R** 重新读取。
- 以表格打开的文件，其**文本和十六进制** 只有在您切换过去时（**T**、**H**）才会读取：在此之前 Xylem 只读取文件开头，因此大表格可以立即打开。

自动预览（F7）不打开数据库，其他表格也只读取开头的若干行。其他格式目前仍受下文的限制。

## 限制

除上述大表格外，一个表格最多容纳 50,000 行和 256 列，耗时也不超过查看器其他限制所允许的范围：3 秒（自动预览中为 100 毫秒）；解压后超过大小限制（自动预览中为 1 MiB）的电子表格不会以表格形式打开。超出部分不会显示，筛选也看不到，标题栏会提示：`(showing first 50,000 rows)` 或 `(stopped by the time limit: showing N rows)`。读取表格时屏幕保持可用，并有提示说明；按 Esc 停止读取并显示已读到的内容，`(stopped by Esc: showing N rows)`，再按一次 Esc 关闭查看器。单元格最多显示 2,048 个字符，之后显示 `…`。控制字符和文本方向字符显示为 `·`。

当电子表格（XLSX、XLSB、XLS、ODS）的行数超过这一限制时，标题和提示会说明：`(the sheet has more than 50,000 rows, the most Xylem shows: open it in Excel or another spreadsheet program to see them all (O))`，即请用 Excel 或其他电子表格程序打开以查看全部行。按 **O** 会用系统为它指定的程序打开。

## 由 C 库读取的表格

SQLite 数据库（`.db`、`.sqlite`、`.sqlite3`）和 Parquet 文件由 C 语言编写的库读取，不具备 Rust 的内存安全性。因此，只有按 `V` 才会以表格形式打开。Autoview 会读取光标经过的所有文件，并将这些文件显示为普通内容，同时给出提示 `Parquet or SQLite: V opens the table`。只有在接受此风险时，才打开来源不可信的数据库。`.ods` 和 `.xls` 文件同样只有按 `V` 才会以表格形式打开：它们的读取器会先构建整张工作表，这一步无法中止。
