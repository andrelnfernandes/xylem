# 查找文件和文件夹

Xylem 有多种查找方式。每种方式回答不同的问题，分为三类：前往某个位置、筛选列表，以及查看文件内部。

| 您想要 | 按键 | 结果 |
|---|---|---|
| 按名称片段找到那个文件夹 | 目录树中的 `\|` | 目录树光标跳到那里（[模糊查找](fuzzy.md)） |
| 按名称片段找到列表中那个文件 | 文件窗口中的 `\|` | 文件光标跳到那里（[模糊查找](fuzzy.md)） |
| 一个已知的路径，逐级输入 | `\` 或 `/` | 目录树光标跟随您的输入（[Treespec](treespec.md)） |
| 下一个以某个字母开头的名称 | Shift+字母 | 光标跳到那里（[目录树窗口](tree.md)） |
| 具有某个名称、日期或大小的文件 | `F` | 列表只显示这些文件，直到更改（[Filespec](filespec.md)） |
| 满足某个条件的文件 | `W` | 列表只显示这些文件，直到更改（[SQL](sql.md)） |
| 包含这些单词的文件 | `P` | 结果列表，最匹配的排在前面（[搜索框](sql.md#the-search-box-p)） |
| 包含这段文本的已标记文件 | Ctrl+S | 其他文件被取消标记（[搜索已标记的文件](search.md)） |

## 前往某个位置

**模糊查找**（`|`）、**Treespec**（`\`、`/`）和 **Shift+字母** 移动光标，不改变其他任何东西。记得名称的一部分但不知道它在哪里时，用 `|`；知道路径时，用 Treespec；要在当前文件夹内跳转，用 Shift+字母。

## 筛选列表

**Filespec**（`F`）和 **W** 决定文件窗口显示哪些文件，筛选会一直保留，直到您更改：窗口标题会显示它。`F` 用于名称、日期和大小；`W` 用于 Xylem 所知的文件的任何信息，包括其内容（`contains`、`words`）。两者同时生效，之后 Ctrl+T 会标记所有通过筛选的文件。

要在整个目录树中查找，先打开 Branch（`B`）或 Showall（`S`）：筛选和 `|` 随后会作用于其中所有已载入的文件。

## 查看文件内部

**搜索框**（`P`）随输入按文件中的单词查找文件，在用 Alt+N 建立了索引的分支上可即时返回结果。**Ctrl+S** 在已标记的文件中搜索一段文本，并取消标记不包含它的文件，之后 Ctrl+V 逐个显示匹配处。在 `W` 中，`contains('text')` 和 `words('a b')` 作为条件的一部分完成同样的工作。

## 标记找到的内容

要对多个文件进行操作时，以上每种方式都可以最终得到标记：

- `|` 和 `P`：Ctrl+T 标记选中的结果；在 `|` 中，Alt+T 标记整个列表。
- `F` 和 `W`：目录树中的 Ctrl+T 标记所有通过筛选的文件。
- Ctrl+S 只保留包含该文本的文件的标记。

之后 Ctrl+C、Ctrl+M、Ctrl+D 和批处理会作用于已标记的文件。请参阅[标记](tagging.md)。
