# 模糊查找 (|)

`|` 按名称片段在目录树的任意层级查找文件夹或列表中的文件：`cfgxy` 可找到 `config/xylem`，`rdme` 可找到 `README.md`。结果随输入显示在提示行上方，最匹配的排在前面，窗口的光标跟随选中的结果。

要逐级前往已知的路径，[Treespec](treespec.md) 更快。要按名称、日期或大小，或按内容挑选多个文件，请参阅[查找文件和文件夹](finding.md)。

## 搜索范围

`|` 搜索什么，取决于在哪个窗口中打开它：

- **在目录树中：** 已载入的文件夹，按其从目录树根开始的路径（`docs plan` 可找到 `docs/plans`）。隐藏文件夹及其内部的内容，只有在目录树显示它们时才会被搜索。
- **在文件窗口中：** 当前列表中的文件，[Filespec](filespec.md) 和 [SQL 条件](sql.md)（`W`）均生效。在目录中按名称搜索；在 Branch 和 Showall 中也按路径搜索（`src fzrs` 可找到 `src/fuzzy.rs`）。

要在整个目录树中查找文件，先打开 Showall（`S`），再按 `|`。

只搜索已载入的内容，不会从磁盘或网络读取任何东西：因此在[远程主机](remote.md)上、[归档文件](archives.md)内和[云存储挂载](cloud.md)上的效果都一样。

## 匹配方式

- **字母按顺序**，不必相连：`rdme` 可找到 `README.md`。
- **空格分隔各个词**，每个词都必须匹配，顺序不限：`xy docs` 可找到 `xylem/docs` 和 `docs/xylem`。
- **大小写**不区分，除非该词含有大写字母：`Rd` 找不到 `readme`。每个词各自决定。
- **最匹配的排在前面：** 相连的字母比分开的字母得分高；单词开头的字母（在开头、在 `/`、`_`、`-`、`.` 或空格之后，或小写转为大写之处，如 `fileSpec`）比中间的字母得分高；名称中的匹配比上层文件夹中的匹配得分高。得分相同时，路径较短的排在前面，然后按目录树或列表的顺序。

匹配的字母以按键颜色显示。名称太长、窗口放不下时，会从左边截断并显示 `…`，以便保留名称的结尾。

## 屏幕显示

右上角的计数显示搜索进展：

| 显示 | 含义 |
|---|---|
| `type pieces of a name` | 提示行为空 |
| `120 found · searching 40%` | 仍在搜索目录树；列表会陆续填充 |
| `120` | 完成：所有匹配项都在列表中 |
| `500 best of 15,894` | 完成：列表保留最匹配的 500 项 |
| `nothing matches` | 完成，没有匹配项 |

大型目录树会在您输入时分步搜索，因此最初的结果立即出现，其余的随后跟上。在末尾添加字母时，只在已经匹配的结果中继续搜索。如果提示行打开期间目录树发生变化（载入、释放或重新读取了某个文件夹），搜索会重新开始。

文件前的 `*` 表示该文件已被标记；文件夹后的 `3*` 表示其中有多少个文件已被标记。

## 按键

| 按键 | 功能 |
|---|---|
| ↑ ↓ | 选择上一个或下一个结果；窗口的光标跟随 |
| PgUp PgDn、Home End | 向上或向下翻一页选择，或选择第一个或最后一个结果 |
| Enter | 停在光标所在位置并关闭提示行 |
| Esc | 回到光标原来的位置并关闭提示行 |
| Ctrl+T | 标记选中的结果（若已标记则取消标记），并选择下一个 |
| Alt+T | 标记列表中各结果的文件 |
| Ctrl+U | 清空提示行 |

开启[鼠标](mouse.md)时，单击选择结果，双击前往该处。

## 从结果中标记

在文件上按 **Ctrl+T** 会标记它；在文件夹上，会标记该文件夹中文件窗口会显示的文件（Filespec 和 `W` 生效）。如果它们都已被标记，则取消标记。之后选择会移到下一个结果，因此 Ctrl+T、Ctrl+T、Ctrl+T 会依次标记各个结果。

**Alt+T** 标记列表中每个结果的文件：最多为显示的 500 项。匹配项更多时，列表下方的提示会说明有多少项被略去。在尚未载入的文件夹上按 Alt+T 不会标记其中任何内容，提示会说明跳过了多少个。

和其他标记一样，提示行关闭后标记仍然保留：之后 Ctrl+C、Ctrl+M、Ctrl+D 和批处理会作用于它们。请参阅[标记](tagging.md)。

标记所有匹配项（而不只是列表中的 500 项）是一个选项，默认关闭：开启后 Alt+T 可能会标记数千个您没有看到的文件。开启前请阅读[模糊查找中标记全部匹配项](configuration.md#tagging-every-match-of-the-fuzzy-find)。
