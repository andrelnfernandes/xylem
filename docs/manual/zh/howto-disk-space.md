# 找出占满磁盘的内容

本指南演示如何从用户主目录逐层深入，找到其中占用空间最大的文件并删除其中之一。

## 操作步骤

1. 在目录树中，将光标置于要检查的目录上，按 Alt+U。Xylem 载入该分支并按占用空间从大到小列出其中的文件夹和文件。
2. 移动光标至某个文件夹（名称以 `/` 开头），按 Enter 列出其中的内容。
3. 对其中最大的文件夹再次按 Enter，重复此操作直至列表中出现具体文件。
4. 移动光标至要删除的文件，按 Del。Xylem 在删除前提示确认。
5. 按 `T` 选择移入回收站，然后按 `Y` 确认。

![五个步骤：在主目录上按 Alt+U、在 projects 上按 Enter、在 backup 上按 Enter、在旧归档上按 Del，并通过 T、Y 将其移入回收站](../../screenshots/howto-disk-space.gif)

底部状态栏显示 `Trashed 1 of 1 files`，随后系统会在不计入该文件的情况下重新计算各项目所占的百分比。

## 单行数据解读

```
     19.0 MiB ████████████████    51%   projects-2026-10.tar.gz
```

| 组成部分 | 含义 |
|---|---|
| `19.0 MiB` | 该项目在磁盘上实际占用的空间 |
| 进度条 | 该项目相对于列表中最大项目的比例 |
| `51%` | 该项目占当前所列目录总空间的比例份额 |
| 名称 | 若以 `/` 开头则代表文件夹 |

## 列表中的可用按键

| 按键 | 功能说明 |
|---|---|
| Enter | 进入文件夹；在文件上则查看文件 |
| Backspace 或 ← | 返回上级文件夹 |
| `T` | 标记文件，或标记该文件夹下的所有文件 |
| Ctrl+D | 删除已标记的文件 |
| Alt+P | 永久删除该文件夹及其包含的一切 |
| `D` | 在当前所列目录中查找重复文件 |
| `\` | 关闭列表并将目录树光标定位到当前所列目录 |
| Esc | 关闭列表 |

## 异常排查

- **某行以 `>` 开头。** 这是一个挂载在该处的其他磁盘/文件系统。它不计入当前统计，在其上按 Enter 会为该磁盘单独打开独立统计列表。
- **某行以 `!` 或 `.` 开头。** 该文件夹或其内部某些项目无法读取（通常因权限不足）。其实际占用空间可能大于当前显示的数值。
- **显示大小与文件窗口不一致。** 此处列表默认显示的是磁盘上的实际占用空间（按整块分配）。按 `A` 可切换为文件自身的表观大小。
