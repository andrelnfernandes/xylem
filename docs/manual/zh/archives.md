# 归档文件

## 打开归档文件 (Alt+F5)

在文件窗口中按 Alt+F5 可将以下归档文件作为只读目录树打开：

- `.zip`，以及 `.jar`、`.war` 和 `.apk`；
- `.7z`（不支持加密的 7z 归档文件）；
- `.tar`，包括未压缩或使用 gzip（`.tar.gz`、`.tgz`）、xz（`.tar.xz`、`.txz`）、bzip2（`.tar.bz2`、`.tbz2`）或 zstd（`.tar.zst`）压缩的归档。

在归档内部，导航、[Filespec](filespec.md)、Branch、Showall、标记、[查看器](viewer.md)、[Ctrl+S](search.md) 和 [比较](compare.md) 均可正常使用，而 [复制](copy-move.md)（包括 Ctrl+C 和保留路径的 Alt+C）则用于从中解压文件。在目录树中按 `Esc` 可关闭归档文件并返回原位置。

出于安全考虑，包含 `..` 或绝对路径的条目会被忽略，且归档内部的符号链接绝不会被解压出来。

压缩的 TAR 没有索引，因此打开时需要解压全部内容。这在后台进行：底部状态栏显示进度，`Esc` 可取消，Xylem 的其余部分仍可响应；完成后窗口才会切换。条目超过 1,000,000 个的压缩包会被拒绝。

## 创建归档文件 (F5 / Ctrl+F5)

根据您输入的名称创建 `.zip`、`.tar`、`.tar.gz` 或 `.tgz` 归档，包含当前文件（F5）或所有已标记的文件（Ctrl+F5）；按 F2 可 [选择文件夹](picker.md)。归档内部的相对路径从列表的根目录算起，与 Alt+C 一致：在 Branch 视图中，子文件夹结构会被保留。打包过程中会显示进度，按 `Esc` 可取消；归档会先写入临时文件，仅在完成时才命名为目标文件名。符号链接会作为链接存储。不会覆盖已存在的文件。
