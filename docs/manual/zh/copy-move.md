# 复制与移动

`C` 复制光标下的文件，`M` 移动它；Ctrl+C 与 Ctrl+M 操作已标记的文件；Alt+C 与 Alt+M 操作已标记的文件并重建其路径。系统会提示输入目标位置。

## 目标位置

可以是目录（相对于目录树光标所在目录的相对路径、绝对路径或以 `~` 开头的路径），或者对于单个文件，也可以是新文件名。在 [分屏](split.md) 状态下，会默认建议另一窗口的目录。按 **F2** 打开目录树以 [选择文件夹](picker.md)；按 **↑** 调出之前用过的目标路径。

未分屏时，提示行打开时为空，与 [Log](treespec.md) 相同，按 **↑** 可调出同一批位置：复制或移动时用过的目标文件夹，以及用 Log 打开过的目录，最近的在前。提示行为空时按 Enter 不执行任何操作。

按 **F11** 可把一个 [书签](bookmarks.md) 填入提示行。

若目标文件夹尚不存在，确认后会自动创建。

## 是否保留路径

Ctrl+C / Ctrl+M 会将所有已标记的文件直接放入目标目录。Alt+C / Alt+M 则会在目标目录中重建每个文件的子路径；路径从何处算起取决于路径模式。例如，当从 `src/ops`（列表的根目录：当前目录、Branch 的根目录或 Showall 中目录树的根）列出 `/home/me/proj/src/ops/mod.rs` 并复制到 `dest` 时：

| 模式 | 结果 | 说明 |
|---|---|---|
| Full | `dest/home/me/proj/src/ops/mod.rs` | 从磁盘根目录算起，与 ZTreeWin 一致（默认） |
| Tree | `dest/src/ops/mod.rs` | 从 Xylem 目录树的根算起（此处为 `proj`） |
| Current | `dest/ops/mod.rs` | 从列表的根目录算起，包含该目录本身的名称 |
| Relative | `dest/mod.rs` | 仅保留列表根目录之下的相对路径 |

在提示行中，按 **F6** 切换是否保留路径，按 **F7** 循环切换路径模式；两者都会显示在提示行中。初始模式由 `copy_paths` 设置（见 [配置](configuration.md) 第 4 页）。在归档文件内部，路径最多从归档文件的根算起。

## 当目标文件已存在时

Xylem 会询问 **Yes** / **No** / **All** / **Skip all**，并显示新文件与现有文件的大小和日期，以及现有文件是更新还是更旧、更大还是更小。按 `Esc` 取消整个操作。

## 安全性

复制时会先写入临时文件，仅在完成时才替换目标文件：中途取消或出错绝不会留下写了一半的残缺文件。权限与修改时间会被保留，符号链接会作为链接原样复制。跨磁盘移动会先复制再删除源文件。

另请参阅：[标记](tagging.md)、[归档文件](archives.md)（复制可从中解压文件）。
