# 书签

书签可以让您用单个按键（`0`–`9`、`a`–`z`）快速跳回常用的目录。书签会随提示行历史记录一起在多次运行之间保存。

- **Ctrl+F11**（或在目录树中按 Ctrl+B）保存当前目录：接着按下要分配给它的按键即可。
- **`'`** 跳转到书签：按下书签对应的按键。在同一提示行中，再按一次 `'` 或按 Enter 会打开书签列表，按 `+` 则保存当前目录。
- **F11**（或 Alt+B）打开书签管理器：↑ ↓ 选择，Enter（或书签对应的按键）跳转，**F2** 为书签命名，Del 删除，Insert 或 `+` 保存当前目录，Esc 关闭。
- **在 [Log](treespec.md)、[Copy 和 Move](copy-move.md) 的提示行中按 F11**，会打开同一个列表用来选择位置：Enter（或书签对应的按键）把它填入提示行，您仍需在那里确认；Esc 返回您原先输入的内容。

不在当前目录树内的书签目录会作为新的目录树打开，效果与 [Log](treespec.md) 相同。在文件窗口中，Ctrl+B 是 [批处理](execute.md)，因此在那里请使用 Ctrl+F11 保存书签。

## 名称

名称说明书签的用途，例如“Oracle 服务器”“Postgres 容器 环境 1”。在管理器中，在书签上按 **F2** 会询问名称，并给出当前名称供编辑；名称留空即删除名称。名称显示在位置之前，而位置始终显示在旁边，因此名称无法掩盖书签实际指向的地方。名称最多 60 个字符，不能包含控制字符或文本方向字符。

## 远程主机与容器

在 [远程主机](remote.md) 或容器的窗口中，Ctrl+F11 会以能打开该文件夹的地址保存它：`ssh://oracle@db01/u01/app`、`docker://postgres-env1/var/lib/postgresql`。跳转到它时，会像在 Log 中输入该地址一样进行连接，若 ssh 需要密码则会询问；不会保存任何密码。如果窗口已经连接在这台主机上，并且该文件夹在其目录树中，则只移动光标。路径中含有空格的文件夹无法以这种方式保存，因为地址中不能包含空格。

管理器会把已不存在的本地文件夹标记为 `[not found]`。它不会检查远程书签，也不会检查云挂载或网络共享上的文件夹：那样会等待网络。
