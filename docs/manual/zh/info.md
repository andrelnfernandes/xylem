# 信息

- **Info (Alt+I)：** 文件或目录的类型、大小、权限、所有者与用户组、日期（修改、访问与状态更改）、inode、硬链接数和所在设备；对于符号链接，显示其指向的目标；对于目录，还显示该目录及其分支中已载入的统计数据。
- **Avail（在目录树中按 `A`）：** 已挂载的文件系统及其总容量、已用空间、可用空间和使用百分比，类似于 `df`。
- **统计信息 (`?`)：** 当前窗口已载入的数据、当前列表、已标记文件以及磁盘信息（挂载点、可用与已用空间）；下方还显示机器信息（系统与内核、CPU、运行时间、负载、内存与交换空间、shell、终端）、网络信息（各网卡接口的地址、网关与 DNS）以及 Xylem 自身的信息（版本、PID、内存占用、可执行文件与配置文件路径）。

## 目录大小 (Alt+K)

在目录树中每个目录的右侧显示 **S**ize（总大小，单位为 K）、文件数量 **C**ount 或百分比 **P**ercent；按 **N**one 关闭显示。在选择显示内容之前，可按 **A**ll 或 **T**agged 选择统计所有文件还是仅统计已标记文件，按 **B**ranch 或 **D**irectory 选择累加整个分支还是仅计算该目录本身。尚未载入的目录会显示 `?`。每个窗口都有各自独立的设置。

**百分比 (Percent)** 显示每个分支占其父目录的百分比，并附带进度条：同级中最大的目录会填满进度条，其余同级目录按比例绘制，从而让占用空间的目录一目了然。颜色表示它占父目录的比例：不超过 10%（大多数主题中为绿色）、不超过 40%（琥珀色）或更高（红色）。百分比模式始终累加整个分支。父目录自身直接包含的文件也计入父目录的总大小，因此各子目录的占比之和可能小于 100%。要找出填满磁盘的元凶，请先按 `*` 载入整个分支：尚未载入的目录会被视为大小为空。当通过 rclone 挂载 Google Drive 或 S3 时，可以用这种方法找出占用云端空间的目录：详见 [云存储](cloud.md)。对于整个本地磁盘，[磁盘用量视图](usage.md)（Alt+U）功能更全面：将文件与文件夹排在一起、按实际磁盘占用计算、硬链接只计算一次。
