# 磁盘用量 (Alt+U)

查看空间去向。**Alt+U** 会载入当前目录的整个分支，并按占用空间从大到小列出其中的文件夹和文件，同时显示进度条及其占当前目录的百分比。按 Enter 进入文件夹；逐层深入，即可找到填满磁盘的内容。


> 在 0.7 及更早版本中，磁盘用量是 Alt+W，而 Alt+U 会取消全部标记（现在只用 Ctrl+U）。参见 [Ctrl 与 Alt](tagging.md#ctrl-与-alt-的含义)。

```
       32.9 GiB ████████████████   45%   wsl-ubuntu-backup.tar
       18.9 GiB █████████▏         26%  /projetos
 .      5.5 GiB ██▋               7.6%  /.local
 >    154.6 MiB                      -  /boot
```

- **进度条** 以当前目录中最大的项目为基准绘制，轨道宽度与最大项相同，使各项之间的差异清晰可见；**百分比** 则是该项目占当前目录的份额。颜色表示该份额的大小：不超过 10%（大多数主题中为绿色）、不超过 40%（琥珀色）或更高（红色）。每个主题都有自己的颜色配置（`[colors]` 中的 `bar_low`、`bar_mid` 和 `bar_high`）。
- **文件夹与文件混合排列**，统一按大小排序：单个大文件（如旧备份、ISO 镜像）会与文件夹一起排列展示。文件夹名称以 `/` 开头。
- **底部状态行** 显示当前目录的总计数据：磁盘实际占用、表观大小、文件总数，以及它们占磁盘已用空间和整个磁盘总容量的比例。在磁盘根部，它会显示已统计到的空间占磁盘已用空间的百分比：差额部分通常位于无权限读取的文件夹、文件系统自身的元数据，或已删除但仍被进程打开的文件中。
- **右侧面板** 显示光标所在项目的详细信息：磁盘占用与表观大小、文件数、日期，以及它占已用空间和整个磁盘的比例。

## 磁盘占用与表观大小

默认情况下，显示的大小是 **磁盘上的实际占用空间**，计算方式与 `du` 相同：文件按整块（通常为 4 KiB）分配空间，因此小文件占用的空间会大于其自身大小，而稀疏文件（如虚拟机磁盘）或压缩文件占用的空间则会小于其表观大小。按 **A** 可切换为 **表观大小 (apparent)**，即文件本身的字节大小。底部状态行始终同时显示这两者。

## 分析统计规则

- **每次只统计一个磁盘。** 挂载在分支内部的其他文件系统（另一块磁盘、`/boot`、U 盘、rclone 挂载的文件夹、`/proc`）不会被载入或计入当前统计：它们会标有 `>` 并显示该文件系统自身已使用的空间，对其按 Enter 可单独开始分析该文件系统。
- **硬链接只计算一次。** 指向同一文件的多个名称只占用一份空间：第一次遇到的计入大小，其余的标有 `H` 且不计大小。
- **隐藏文件也会计入**，即使目录树未显示隐藏文件，以确保总计大小准确无误。
- 符号链接（`@`）仅计算链接本身的大小，不会追踪其指向的目标。

## 标记符号

| 标记 | 含义 |
|---|---|
| `>` | 另一个磁盘（未计入当前目录总额） |
| `!` | 无法读取该文件夹（通常是因为权限不足） |
| `.` | 内部有部分内容无法读取：实际占用可能比显示的更大 |
| `H` | 已计入大小的文件的另一个硬链接 |
| `@` | 符号链接或特殊文件 |
| `e` | 空文件夹 |

## 处理找到的内容

确认提示与文件窗口相同，操作后总计会立即更新，视图保持打开。

- **在文件夹上按 Del** 会删除该文件夹及其全部内容；如果您的设置如此，则移入回收站。Alt+P 则永久删除，并需要输入 Prune 的确认文字。
- **标记文件夹** 会标记其中的所有文件，包括隐藏文件。`■` 表示已标记的文件或整个文件夹，`□` 表示部分标记的文件夹，底部状态行显示当前列出的文件夹中已标记的数量及其占用空间。Ctrl+D 删除这些文件。关闭视图后标记仍然保留，可用于 Copy 或 Move。
- **绝不触碰其他磁盘。** `>` 行不能标记或删除，标记或删除一个分支时遇到挂载的其他磁盘会停止。Del 会拒绝内部挂载了磁盘的文件夹；Alt+P 会删除除该磁盘以外的所有内容。
- 在压缩包内或远程机器上，只能标记和查看。

## 按键

| 按键 | 功能 |
|---|---|
| ↑ ↓ PgUp PgDn Home End | 移动光标 |
| Enter 或 → | 进入文件夹（在 `>` 上：分析该磁盘）；在文件上：查看文件 |
| Backspace 或 ← | 返回上一级文件夹 |
| `\` | 关闭视图，并将目录树定位到当前列出的文件夹 |
| `A` | 切换磁盘占用空间或表观大小 |
| `C` | 显示或隐藏文件数量 |
| `S` | 按大小、名称、文件数量或日期排序 |
| `T` / `U` | 标记或取消标记该文件，或该文件夹中的所有文件 |
| Ctrl+T / Ctrl+U | 标记或取消标记当前列出的文件夹中的全部内容 |
| Del、Shift+Del | 删除该文件或文件夹（Shift：永久删除） |
| Ctrl+D、Ctrl+Shift+Del | 删除当前列出的文件夹中已标记的文件（Shift：永久删除） |
| Alt+P | 对该文件夹执行 [Prune](delete.md) |
| `V` | 查看该文件 |
| `D` | 在所列文件夹中查找[重复文件](duplicates.md) |
| F3 | 重新读取当前列出的文件夹 |
| Esc 或 Alt+U | 关闭视图 |

在此视图打开时，Tab、F8、Alt+X（内置终端）和 F12 均可照常使用。

分析大型磁盘会将每个文件夹载入内存：这需要一点时间（底部会显示进度，按 Esc 可取消）和一定的内存（数百万个文件大约占用几百兆字节）。以普通用户身份运行时，系统的某些文件夹无法读取（标为 `!`），因此 `/` 的统计总额会偏小：底部状态行会说明差额情况。
