# 菜单、Ctrl 与 Alt

底部状态栏列出了在当前获得焦点的窗口中可用的命令。共有四个菜单，左侧的标题标明当前显示的是哪一个。

| 标题 | 显示时机 | 其命令作用于 |
|---|---|---|
| DIR | 目录树获得焦点 | 光标下的目录 |
| FILE | 文件窗口获得焦点 | 光标下的文件 |
| CTRL | 按住 Ctrl，或按 F4 之后 | 已标记的文件 |
| ALT | 按住 Alt，或按两次 F4 之后 | 参见 [Alt 菜单](#alt命令的另一种变体) |

在归档文件内标题为 ARCHIVE，在远程主机上为 REMOTE。两者都会省略在对应环境中无法使用的命令。

## 阅读菜单

每个词代表一个命令，其中的大写字母即为按键：`Copy` 是 `C`，`eXecute` 是 `X`，`iNdex` 是 `N`。在 CTRL 和 ALT 菜单中，按键则是配合 Ctrl 或 Alt 按下该字母。

这些词按其按键字母的字母表顺序排列，Quit 始终排在最后。下方是一行功能键与符号（`F3 relog`、`? stats`）。

底部状态栏共有三行。在足够宽的屏幕上，如果一行足以容纳所有词，则显示为两行。在较窄的屏幕上，所有词会等长缩写，放不下的条目以 `…` 标记。

## Ctrl：已标记的文件

单独的字母作用于单个项目。同一个字母配合 Ctrl 则作用于列表中的已标记文件：

| 按键 | 单独按下 | 配合 Ctrl |
|---|---|---|
| `C` | 复制文件 | 复制已标记的文件 |
| `D` | 删除文件 | 删除已标记的文件 |
| `R` | 重命名文件 | 用掩码重命名已标记的文件 |
| `T` | 标记文件 | 标记列表中的所有文件 |

在目录树中，“列表”指的是光标下的目录。其中有三个命令的作用范围更广：Ctrl+T 与 Ctrl+U 标记和取消标记所有符合 Filespec 的已载入文件，Ctrl+S 列出所有已载入的已标记文件。

[Ctrl 菜单](commands-ctrl.md)列出了全部命令。

## Alt：命令的另一种变体

Alt 不再重复 Ctrl 的功能。它的作用取决于当前窗口：

- 在目录树中，命令覆盖整个分支。Alt+P (Prune) 删除该目录及其包含的一切，Alt+R 从内存中释放该分支，Alt+C 将该分支与另一个窗口进行比较。
- 在文件窗口中，Alt+C 和 Alt+M 复制和移动已标记的文件，并在目标目录下重建每个文件的路径结构。
- 在两个窗口中，Alt 打开不针对单个文件的工具：Alt+S (Sort)、Alt+F (File display)、Alt+B (Bookmarks)、Alt+I (Info)、Alt+X（内置终端）。

[Alt 菜单](commands-alt.md)列出了全部命令。

## 显示 Ctrl 和 Alt 菜单

**F4** 显示 CTRL 菜单，再次按 F4 显示 ALT 菜单，第三次按 F4 返回平时菜单。当其中一个菜单显示时，下一个按下的字母将附带该修饰键：`F4` `C` 等同于 Ctrl+C。按 Esc 返回且不执行任何操作。

F4 是 ZTreeWin 使用的按键。F9 是 Xylem 之前使用的按键，在它获得自己的命令之前，仍具有相同的作用。

在 kitty、Ghostty、WezTerm、foot 和新版 Alacritty 中，按住 Ctrl 或 Alt 会直接显示对应菜单，松开按键则恢复 DIR 或 FILE 菜单。这些终端能够单独报告修饰键的按下（kitty 键盘协议）。GNOME Terminal、Ptyxis、Terminator 和 Tilix 不支持此功能，因此在这些终端中菜单仅通过 F4 切换。

## Ctrl+M

大多数终端为 Ctrl+M 和 Enter 发送相同的字节，因此 Xylem 无法将它们区分开。在支持 kitty 键盘协议的终端中可以区分，Ctrl+M 用于移动已标记的文件。在其他终端中，请按 `F4` `M`。
