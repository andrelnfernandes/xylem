# Xylem 是什么

Xylem 是一款在终端中运行的文件管理器。它的屏幕布局和按键习惯继承自 XTreeGold 和 ZTreeWin：上方是目录树，下方是光标所在目录中的文件，右侧是统计信息，底部状态栏是一字母命令菜单。运行命令为 `xy`。

## 载入 (Logging)

Xylem 仅在您明确要求时才将目录读取到内存中，并将其保存在内存中。这称为载入（Logging）。`→` 载入单个目录，`*` 载入光标下的整个分支，`-` 从内存中释放分支。

有两个命令可以同时列出多个目录中已载入的文件：`B` (Branch) 列出该目录及其下方所有内容中的文件，`S` (Showall) 列出所有已载入的文件。在这些列表中，按 `T` 标记文件，随后 Ctrl 系列命令即可作用于这些已标记的文件：Ctrl+C 复制它们，Ctrl+D 删除它们，Ctrl+R 用掩码批量重命名它们。

未载入目录中的文件不会出现在任何列表中，也不会受到任何命令的影响。

## 命令涵盖的功能

| 目标操作 | 使用命令 | 主题 |
|---|---|---|
| 复制或移动（保留或不保留源路径） | `C`、`M`、Ctrl+C、Alt+C | [复制与移动](copy-move.md) |
| 删除，以及从回收站恢复 | `D`、Ctrl+Z | [删除](delete.md) |
| 重命名单个文件，或用掩码批量重命名 | `R`、Ctrl+R | [重命名](rename.md) |
| 按名称、日期或大小仅显示部分文件 | `F` | [Filespec](filespec.md) |
| 比较两个目录 | 目录树中的 `C` | [比较](compare.md) |
| 以文本、十六进制或表格查看文件 | `V` | [查看器](viewer.md) |
| 将 ZIP、7z 和 TAR 作为目录打开 | Alt+F5 | [归档文件](archives.md) |

[菜单](menus.md)说明了按键的组织方式，[命令列表](commands.md)列出了所有命令。

## 不可信的文件

Xylem 在读取任何外部文件时都假定其可能带有攻击性。查看文件绝不会执行其中的代码，解压归档文件绝不会写入目标目录之外，每个读取器读到大小上限即停止。[安全](security.md)列出了各项限制以及未涵盖的范围。
