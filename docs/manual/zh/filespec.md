# Filespec：文件过滤器

`F` 设置在文件窗口中显示哪些文件（每个窗口都有各自独立的过滤器）。当前的 filespec 会显示在窗口标题栏中。过滤条件以空格、`;` 或 `,` 分隔，共有三种类型，与 ZTreeWin 一致：

- **名称：** 通配符模式（如 `*.rs`、`a?c*`、`[abc]*`），不区分大小写；用引号括住的名称可以包含空格（如 `"my file*"`）；
- **日期：** `<`、`=`、`>`、`<=`、`>=` 或 `<>` 后跟符合当前配置格式顺序的日期，分隔符可用 `/`、`.` 或 `-`，年份可为 2 位或 4 位（如 `>01/05/2026`；`2026-05-01` 始终有效），或者使用 `TODAY` 和 `TODAY-n`（如 `>TODAY-7` 表示最近 7 天）；
- **大小：** 在运算符后加 `s`（如 `>=s200000`）；也支持 `K`、`M` 和 `G` 单位（如 `>s100M`）。

前导 `-` 表示取反（如 `-*.bak`；`-<s1K` 等同于 `>=s1K`）。在同一类型内部，正向条件之间为“或 (OR)”关系，但紧接着 `<b` 的 `>a` 例外，它表示两者之间的范围（如 `>=01/05/2026,<=31/05/2026` 表示五月）；`<>` 表示排除。不同类型之间为“与 (AND)”关系：`*.txt,=TODAY,<s1000` 表示今天修改且小于 1000 字节的 `.txt` 文件。

`*`（或直接留空）显示所有文件。按 **↑** 调出之前用过的 filespec。

## SQL 条件 (W)

**W** 接受按照 SQL 查询的 `WHERE` 子句编写的条件，在 filespec 之上进一步筛选文件列表。**Ctrl+W** 仅在已标记文件中筛选。它在当前目录、Branch 以及 Showall 视图中均有效，且仅对已载入的文件生效：Xylem 未显示的文件绝不会成为结果。

```sql
ext = 'jpg' AND size > 10000000
ext IN ('md', 'txt') AND age_days < 7
name LIKE 'report%' AND depth >= 2
```

每个文件相当于具有下列列属性的数据行：

| 列名 | 说明 |
|---|---|
| `name` | 文件名（含扩展名） |
| `ext` | 文件扩展名，小写且不含点号（无扩展名时为 `''`） |
| `path`, `dir` | 文件的完整路径及其所在目录路径 |
| `depth` | 文件所在目录相对于目录树根节点的深度层级 |
| `size`, `disk` | 文件字节大小及在磁盘上占用的空间 |
| `modified` | 上次修改时间（本地时间，格式如 `2026-11-15 09:30:00`）：`modified >= '2026-01-01'` |
| `age_days` | 距上次修改经过的天数（`age_days < 7` 表示最近一周） |
| `mode` | 文件权限数值：`mode = 644` |
| `kind` | `file`、`link` 或 `other` |
| `tagged` | 文件是否已被标记：`NOT tagged` |
| `git` | 两个字母的 Git 状态（`' M'`, `'M '`, `'??'`, 干净时为 `'  '`）；在仓库外或未启用 Git 时为 `NULL` |
| `type` | 文件类型描述，如同 Alt+F 所见（`'PNG image, 800 x 600'`, `'Rust source'`, `'empty'`）；仅在条件需要时才读取 |
| `dup` | 重复文件组编号（1, 2...，若运行过 Alt+D）；非重复文件为 `NULL` |

可用运算符与 [表格过滤器](viewer.md#sql-过滤器) 一致：`=`, `<>`, `<`, `<=`, `>`, `>=`, `LIKE`, `ILIKE`, `IN`, `IS NULL`, `AND`, `OR`, `NOT` 以及括号。数字需写完整（如 `10000000`，不支持 `10e6`）。输入不存在的列名会被拒绝并提示可用列；若无任何文件匹配条件，则列表不会发生变动。

文件窗口的标题栏会在 filespec 后显示该条件，底部消息提示匹配的文件数量。按 **Ctrl+T** 可立即全部标记匹配文件，进而执行复制、移动、删除或生成 [Batch](execute.md) 批处理。在 **W** 提示符中留空直接回车可恢复完整列表。首次使用时，按 **↑** 可查看几个可供修改的示例。

### 文件内容搜索：contains()

`contains('text')` 在文件包含该文本时为真（不区分大小写），如同 Ctrl+S 的 [文本搜索](search.md)（文本内的 `*` 代表同行的任意字符）：

```sql
ext IN ('md', 'txt') AND contains('invoice')
contains('TODO') AND NOT contains('DONE')
```

`contains` 在条件运行时始终会直接读取文件，耗时相对较长；索引中只保留完整词语而非片段（索引见下文 `words`）。在开始读取之前，Xylem 会询问确认并显示待读文件数量与总字节数：`No index: read the contents of 1,234 files (2.3 GB)?`（远程机器上会说明需经由 SSH 下载）。仅当结果取决于其内容时才读取文件：例如 `ext = 'md' AND contains('x')` 只会读取 `.md` 文件。底部显示读取进度，按 **Esc** 可随时终止并保留已找到的结果。

某些文件会被跳过，最终提示会统计跳过的文件数：二进制文件（前 8 KiB 内含空字节）、符号链接（不追踪）、超过 256 MiB 的文件以及无法读取的文件。被跳过的文件绝不会出现在结果中，即便是 `NOT contains(...)` 也是如此。

在云挂载上禁止使用 `contains`，因为这需要逐个下载文件。列表保留读取时的结果：后续修改或新增的文件只有在重新运行 **W** 时才会反映。

`contains` 作为独立条件使用，并通过 `AND`, `OR`, `NOT` 结合（如 `contains('a') = 1` 会被拒绝），参数为单引号括起的文本。

### 完整单词与索引：words()

`words('invoice march')` 在文件包含所有指定词语时为真，词语出现的顺序和位置不受限制。词语由连续的字母和数字构成，比较时不区分大小写与重音符号：`words('acao')` 可匹配 `Ação`。与 `contains` 不同，它不匹配词语的局部：`words('invoice')` 不会匹配 `invoices`。单词末尾紧跟 `*` 可匹配以此为前缀的词：`words('invoice*')` 可匹配 `invoice` 与 `invoices`，`words('andre*')` 可匹配 `André` 与 `Andrea`。

```sql
words('invoice 2024') AND ext IN ('txt', 'md', 'csv')
words('fatur* 2024')
```

`words` 可直接由分支的 **索引** 返回结果，无需读取磁盘。在目录树（或文件窗口中光标所在文件夹）按 **Alt+N** 可在确认后对分支内已载入的文件建立索引：它在后台执行一次性读取，按 **Esc** 可中断并保留已完成部分。再次执行时仅读取改动的文件并清除已删除的文件。在已有索引的分支上，Alt+N 提供重新索引或删除索引的选项。

|  | 无索引 | 有索引 |
|---|---|---|
| 响应速度 | 运行 W 时逐个读取文件 | 瞬时完成 |
| 开销 | 每次查询耗费时间 | 建立索引时耗费时间与磁盘空间 |
| 查找内容 | 文本片段 (`contains`) 或单词与前缀 (`words`) | 单词与前缀 (`words`) |
| 后续改动文件 | 始终为当前内容 | 如同无索引，重新读取磁盘 |
| 范围 | 任何已载入位置 | 仅限通过 Alt+N 建立索引的分支 |

在读取前，确认提示会同时说明索引与待读文件情况：`Index: 3,120 files up to date. No index: read the contents of 12 files (1.2 MiB)?`。当所有文件都能由索引直接回答时无需确认，直接提示 `answered by the index`。索引保证结果的准确性：索引建立后发生变更（大小或日期改变）的文件均会立即重新读取。

索引排除的文件：二进制文件、超过 64 MiB 的文件（W 会在要求时读取）、符号链接，以及由 `config.toml` 中 `index_ignore`（或 F12 第 4 页 E 选项）配置的忽略项（默认包含 `.git`, `target`, `node_modules`, `.ssh`, `.gnupg`, `.env`, `*.key`, `*.pem`, `id_rsa`, `id_ed25519`）。移除敏感信息模式会导致私钥等凭据被存入索引。远程机器、压缩包内或云挂载上的文件不建立索引。

索引是文件词语的副本，保存在 Xylem 的缓存目录中（`~/.cache/xylem/index`，仅您本人可读取；Windows 上为 `%LOCALAPPDATA%\xylem\cache\index`），直至通过 Alt+N 删除或手动清理该目录。遇到损坏或版本不兼容的索引，系统会提示并直接读取文件，可通过 Alt+N 重新生成。

## 搜索框 (P)

无需 SQL 的即搜即得体验：按 **P**（或对已标记文件按 **Ctrl+P**）打开悬浮搜索框。

键入单词时，符合条件的文件随按键实时呈现：
- 单词按整词匹配，键入的最后一个词采用前缀匹配（如 `fatura mar` 检索 `fatura mar*`）。
- 分支已有索引（**Alt+N**）时，索引文件结果瞬时呈现。
- 若存在未索引文件，状态栏会显示未索引文件数量与字节大小，只有在明确确认后才会读取（按 **Alt+R**，或无索引结果时按 **Enter**）。
- 每行结果显示标记状态 (`*`)、文件名、所在目录、修改日期，以及匹配的首行文本片段（约 80 字符，过滤所有控制字符与双向文本控制符）。
- 搜索框内的快捷键：
  - **↑ / ↓**, **PgUp / PgDn**, **Ctrl+Home / Ctrl+End**：在结果列表中上下移动。
  - **Enter**：直接跳转至文件窗口中的所选文件并关闭搜索框。
  - **Ctrl+V**：在查看器中打开文件并定位到匹配片段所在行。
  - **Ctrl+T**：直接在搜索框内切换选中文件的标记状态。
  - **Alt+R**：确认并开始读取未索引文件。
  - **Esc**：终止未索引文件的读取，或关闭搜索框。

W 与搜索框是磁盘查询功能的第一阶段：表格形式的查询结果将在后续版本推出。
